## Import

```tsx
import { Kbd } from '@akhatmirzo/ui';
```

## When to use

- **To show shortcuts** — in menu items, [`Tooltip`](./tooltip.mdx),
  [`CommandPalette`](./command-palette.mdx) and help text.
- **Use the `keys` array for combinations** — each key is drawn separately and `mod` adapts to
  the operating system.
- **It only displays.** `Kbd` doesn't listen for key presses — use `useHotkeys` for that (see
  the example below).
- **Don't add a shortcut to every menu item** — keep them for frequent actions.

## Key list (`keys`)

Each item in `keys` is rendered separately. `mod` (case-insensitive) becomes `⌘` on macOS and
iOS and `Ctrl` everywhere else. For a single key, plain `children` is enough.

## Sizes

`sm` (default) is 20px, for inline text and menus. `md` is 24px, for standalone use or next to
larger text.

## Wiring up the shortcut

`Kbd` and `useHotkeys` from `@akhatmirzo/hooks` follow the same `mod` rule, so the key you show
always matches the key you listen for.

```tsx title="search-hint.tsx"
import { useHotkeys } from '@akhatmirzo/hooks';
import { Kbd } from '@akhatmirzo/ui';
import { useState } from 'react';

export function SearchHint() {
  const [open, setOpen] = useState(false);
  useHotkeys('mod+k', () => setOpen(true));

  return (
    <p>
      Search: <Kbd keys={['mod', 'K']} /> {open && '— opened'}
    </p>
  );
}
```

styles on another element.

## Accessibility

- **A semantic `<kbd>` element** marks the content as keyboard input.
- **Symbols** (`⌘`, `↵`, `↑`) aren't always read clearly by screen readers. For important
  instructions, write the word instead: `<Kbd>Enter</Kbd>`.
