## Import

```tsx
import { IconButton } from '@akhatmirzo/ui';
```

## When to use

- **When space is tight and the icon is universally understood** — close (✕), edit, delete,
  toolbar actions. If the meaning isn't obvious, use a [`Button`](./button.mdx) with text.
- **`aria-label` is required.** TypeScript won't compile without it. Screen readers can't see the
  icon and read only this label, so phrase it as an action: "Close", "Edit".
- **Need a visible hint?** Wrap the button in a [`Tooltip`](./tooltip.mdx).
- **In toolbars and table rows**, the `ghost` variant keeps things light.

## Variants

The same variants as `Button`, minus `link`: `primary`, `soft` (default), `outline`, `ghost` and
`danger`. See the [Button](./button.mdx) page for when to use each.

## Sizes

Square: 32, 40 and 48px — the same heights as `Button` and `Input`. The icon scales
automatically to 16 / 18 / 20px. The `sm` size has an invisible 40px hit area.

## States

While `loading`, a spinner replaces the icon, the button keeps focus and clicks are ignored. Try
clicking the first button.

## Props

`IconButton` is a thin wrapper around `Button`. It accepts `loading`, `disabled`, `asChild`,
`labels` and every other `<button>` attribute; `leftIcon`, `rightIcon` and `fullWidth` are not
available here.

`data-loading`.

## Accessibility

- **A name is required.** `aria-label` is enforced by the type — an unnamed button won't compile.
- **Native `<button type="button">`** — activates with `Enter` and `Space` and never submits a
  form by accident.
- **The icon is hidden from screen readers** (`aria-hidden`); the only thing announced is the
  `aria-label`.
- **Loading.** Sets `aria-busy="true"`, and a hidden `aria-live` region announces the
  `labels.loading` text.
- **Small size.** `size="sm"` looks 32px but has a 40px hit area.
