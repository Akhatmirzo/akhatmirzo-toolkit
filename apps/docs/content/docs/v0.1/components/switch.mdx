## Import

```tsx
import { Switch } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Sozlama darhol kuchga kirsa** — bildirishnomalar, qorong'i mavzu, do'konni ochish/yopish.
  Foydalanuvchi "Saqlash" ni bosishi shart emas.
- **"Saqlash" tugmasi bor formalarda** [`Checkbox`](./checkbox.mdx) ishlating — u yerda tanlov
  yuborilgandagina kuchga kiradi.
- **Label holatni emas, sozlamani aytsin:** "Bildirishnomalar", "Yoqilgan/O'chirilgan" emas —
  holatni switch'ning o'zi ko'rsatadi.
- **O'zgarish vaqt talab qilsa** (serverga so'rov), natijani [`toast`](./toast.mdx) bilan
  bildiring yoki xatoda qiymatni qaytaring.

### Data atributlari

Ildiz `<label>` da: `data-state` (`checked` · `unchecked`), `data-size` (`sm` · `md`),
`data-disabled`, `data-invalid`.

## Accessibility

- **Native `<input type="checkbox" role="switch">`** — ekran o'quvchi "switch, yoqilgan" deb
  o'qiydi, `Space` bilan almashtiriladi, forma bilan yuboriladi.
- **Label bosilganda ham** almashadi — butun komponent `<label>` ichida.
- **Bosish maydoni** trekdan kattaroq — barmoq bilan oson tegiladi.
- **Fokus halqasi** faqat klaviatura bilan kelganda chiqadi.
- **Label'siz switch** uchun `aria-label` bering.
