## Import

```tsx
import { Badge } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Holatni ko'rsatish uchun** — "To'langan", "Kutilmoqda", "Bekor qilindi". Rang ma'noga mos
  bo'lsin: `success` — yakunlangan, `warning` — kutilmoqda, `danger` — xato yoki bekor.
- **Faqat rangga tayanmang.** Matn har doim holatni o'zi aytsin — rangni ajrata olmaydigan
  foydalanuvchilar ham tushunsin.
- **Filtr teglari uchun** — `onRemove` bilan ✕ tugmasi chiqadi.
- **Bosiladigan element emas.** Badge — yorliq; harakat uchun [`Button`](./button.mdx) ishlating.
- **Qisqa yozing** — bir-ikki so'z. Uzun matn kesiladi (`truncate`).

## Ranglar

`color`: `neutral` (standart), `primary`, `success`, `warning`, `danger`, `info`. Ranglar
tokenlardan olinadi, shuning uchun dark mode'da ham kontrast saqlanadi.

## Variantlar

`variant`: `soft` (standart) — och fon, `solid` — to'q fon, ko'proq e'tibor tortadi, `outline` —
chegara va rangli matn.

## Olib tashlash

`onRemove` berilsa, ✕ tugmasi chiqadi. Tugmaning `aria-label` ini `labels.remove` bilan aniq
qiling — "Toshkent filtrini olib tashlash" "Olib tashlash" dan ko'ra tushunarli.

### Data atributlari

Ildiz elementda: `data-variant`, `data-color`, `data-size`. Stilni boshqa elementga qo'llash
uchun `badgeVariants` ham eksport qilinadi.

## Accessibility

- **Oddiy matn** — `<span>`, ekran o'quvchi ichidagi matnni o'qiydi. Nuqta `aria-hidden`.
- **✕ tugmasi** — haqiqiy `<button>`: `Tab` bilan fokuslanadi, `Enter` / `Space` bilan bosiladi.
  Ko'rinishi 16px, lekin bosish maydoni kattaroq.
- **Teg o'chirilgach** fokus yo'qolmasligi uchun uni keyingi tegga yoki qidiruv maydoniga
  o'zingiz o'tkazing.
