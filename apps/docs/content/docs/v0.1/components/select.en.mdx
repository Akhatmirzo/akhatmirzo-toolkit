## Import

```tsx
import { Select } from '@akhatmirzo/ui';
```

## When to use

- **One choice out of roughly 5–15 options** — a region, a payment method, a status. With three
  options or fewer, a [`RadioGroup`](./radio-group.mdx) works better: everything is visible at
  once.
- **Need search? Use [`Combobox`](./combobox.mdx).** `Select` has no search on purpose; long
  lists like cities or products belong in a Combobox.
- **Several values** also call for `Combobox` with `multiple` — `Select` returns a single value.
- **Always give it a name:** put it inside a [`Field`](./field.mdx) or pass `aria-label`.
- **Not for commands.** Actions like "Edit" or "Delete" go in a
  [`DropdownMenu`](./dropdown-menu.mdx).

## Groups and separators

`Select.Group` puts options under a heading, and `Select.Separator` draws a line between groups.
The selected option gets a ✓ mark.

<ComponentPreview name="archive/v0.1/select/groups" />

```tsx
<Select defaultValue="fer">
  <Select.Item value="tsh">Toshkent</Select.Item>
  <Select.Group label="Vodiy">
    <Select.Item value="and">Andijon</Select.Item>
    <Select.Item value="fer">Farg'ona</Select.Item>
  </Select.Group>
  <Select.Separator />
  <Select.Group label="Janub">
    <Select.Item value="qash">Qashqadaryo</Select.Item>
  </Select.Group>
</Select>
```

## Sizes

Three sizes — 32, 40 and 48px, the same heights as `Input` and `Button`, so they line up in a
row. The panel is as wide as the trigger; long lists scroll after 320px.

<ComponentPreview name="archive/v0.1/select/sizes" />

## States

Inside a `Field`, `disabled`, `error` and `required` are wired up for you — no need to repeat
them on `Select`. Without a `Field`, pass `invalid` and `disabled` directly. To disable a single
option, set `disabled` on `Select.Item`; keyboard navigation skips it.

<ComponentPreview name="archive/v0.1/select/states" />

## Options with icons

The `icon` prop on `Select.Item` reserves a 16px slot before the label. Handy for short markers
such as status colors.

## In a form

When you pass `name`, `Select` renders a hidden native `<select>`, so the value is submitted with
`FormData`. Validate the empty case yourself and show the message through the `error` prop of
`Field`.

<ComponentPreview name="archive/v0.1/select/form" align="start" />

## Inside a dialog

`Select` works inside a [`Dialog`](./dialog.mdx) or a [`Drawer`](./drawer.mdx) out of the box:
the panel detects the modal layer and raises its z-index, so the list opens above the dialog.
There is nothing to configure — see the "Select and Combobox inside a dialog" section on the
Dialog page for a working example.

| ------------------ | ------- | --------------------------------------- |
| `data-size`        | trigger | `sm` · `md` · `lg`                      |
| `data-state`       | trigger | `open` · `closed`                       |

| `data-invalid`     | trigger | present in the error state              |

## Keyboard

| Key                           | Action                                             |
| ----------------------------- | -------------------------------------------------- |
| `Enter` / `Space` / `↓` / `↑` | Opens the panel when the trigger is focused        |
| `↓` / `↑`                     | Moves between options (disabled ones are skipped)  |
| `Home` / `End`                | First / last option                                |
| A letter                      | Jumps to the next option starting with that letter |
| `Enter` / `Space`             | Selects and closes                                 |
| `Esc`                         | Closes without changing the value, focus returns   |

## Accessibility

- **Roles.** The trigger is `role="combobox"` with `aria-expanded`, the panel is a `listbox`,
  and each option is an `option` with `aria-selected`. It is built on Radix Select.
- **Field wiring.** Inside a `Field`, the label, `description` and `error` are linked to the
  trigger through `aria-labelledby` / `aria-describedby`. Errors set `aria-invalid="true"`;
  `required` sets `aria-required="true"`.
- **Focus.** When the panel opens, focus moves to the selected option; on close it returns to
  the trigger.
- **Never leave it unnamed.** Without a `Field`, add an `aria-label` (for example
  `aria-label="Currency"`).
- **Decorations.** The chevron, the ✓ mark and `icon` are `aria-hidden`, so screen readers only
  read the option text.
