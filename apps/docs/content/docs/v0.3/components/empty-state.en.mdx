## Import

```tsx
import { EmptyState } from '@akhatmirzo/ui';
```

## When to use

- **When a list or table is empty** — "No orders yet". Instead of blank space, explain what
  happened and what to do next.
- **When a search or filter returns nothing** — suggest changing the query or clearing filters.
- **On first run** — guide people to their first action (`size="lg"`).
- **One main action** — `action` (`primary`), with an optional `secondaryAction` (`ghost`).
- **Keep the title short and the description useful** — not "Nothing here", but "Your first order
  will show up here".

`size`: `sm` has 24px vertical padding, `md` (default) 40px and `lg` 64px, with a 64px icon circle
and a larger title.

### Data attributes

On the root: `data-size` and `data-bordered` (when bordered). `emptyStateVariants` is exported too,
so you can apply the styles to another element.

## Accessibility

- **The title is a real `h*` element** — `h3` by default. Set `headingLevel` to fit your page so the
  heading order stays intact.
- **The icon is decorative** — it's `aria-hidden` together with its circle.
- **Actions** are your own buttons and work with the keyboard as usual. On narrow screens
  (< 640px) they stack and go full width.
- **If the content changes dynamically** (search) and you want it announced, put `role="status"` on
  the surrounding container.
