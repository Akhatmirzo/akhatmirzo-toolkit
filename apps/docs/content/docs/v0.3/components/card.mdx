## Import

```tsx
import { Card } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Bir mavzudagi ma'lumotni guruhlash uchun** — buyurtma, mahsulot, statistika, sozlamalar
  bo'limi.
- **Kompozitsiyadan foydalaning:** `Card.Header` (sarlavha, izoh, o'ngdagi harakat),
  `Card.Body`, `Card.Footer`. Hammasi ixtiyoriy.
- **Butun karta bosiladigan bo'lsa** — `interactive` va `asChild` bilan `<a>` yoki `<button>`
  bering, `<div onClick>` emas.
- **Kartani kartaning ichiga qo'ymang.** Ichki guruhlash uchun [`Divider`](./divider.mdx) yoki
  bo'shliq yetarli.

## Variantlar

`elevated` (standart) — soya va chegara, oq fonda ajralib turadi. `outline` — faqat chegara,
zich ro'yxatlar uchun. `soft` — chegarasiz, `surface-muted` fon.

<ComponentPreview name="archive/v0.3/card/variants" />

## Ichki bo'shliq

`padding`: `none` — 0, `sm` — 16px, `md` (standart) — 24px, `lg` — 32px. Bo'limlar orasidagi
masofa ham shunga moslashadi.

<ComponentPreview name="archive/v0.3/card/padding" />

## Rasm bilan

`padding="none"` va `overflow-hidden` — rasm karta chetiga tegib turadi, matnga bo'shliqni
o'zingiz berasiz.

<ComponentPreview name="archive/v0.3/card/media" />

## Bosiladigan karta

`interactive` hover'da soyani oshiradi va kursorni "qo'l" qiladi. Bu faqat stil — klaviatura
uchun `asChild` bilan `<a>` yoki `<button>` bering: shunda karta `Tab` bilan fokuslanadi va
`Enter` bilan ochiladi.

<ComponentPreview name="archive/v0.3/card/interactive" />

```tsx
import Link from 'next/link';

<Card interactive asChild>
  <Link href="/hisobotlar/sotuv">
    <Card.Header title="Sotuvlar" description="Oktyabr" />
  </Link>
</Card>;
```

### Card.Body va Card.Footer

`CardBody` va `CardFooter` — oddiy `<div>` lar, barcha atributlarini qabul qiladi. `Body` matnni
`text-sm` qiladi, `Footer` bolalarni bir qatorga terib, `gap-2` bilan joylaydi (o'ngga surish
uchun `className="justify-end"`).

### Data atributlari

`Card` ildizida: `data-variant`, `data-padding`, `data-interactive`. Stilni boshqa elementga
qo'llash uchun `cardVariants` ham eksport qilinadi.

## Accessibility

- **Oddiy `<div>`** — rol qo'shilmaydi. Mazmunli bo'lim bo'lsa, `asChild` bilan `<section>` yoki
  `<article>` bering.
- **`Card.Header` sarlavhasi `<h3>`.** Sahifadagi sarlavhalar tartibiga mos kelmasa, `title`
  o'rniga `children` ga o'z sarlavhangizni yozing.
- **Bosiladigan karta** faqat `asChild` bilan haqiqiy `<a>` / `<button>` bo'lganda klaviaturada
  ishlaydi; fokus halqasi butun kartaga chiziladi.
