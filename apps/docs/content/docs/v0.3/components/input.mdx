## Import

```tsx
import { Input } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Qisqa, bir qatorli qiymatlar uchun** — ism, email, qidiruv, summa. Ko'p qatorli matnga
  [`Textarea`](./textarea.mdx).
- **Doim [`Field`](./field.mdx) ichida** ishlating — label, izoh va xato o'zi ulanadi. Label'siz
  (masalan, qidiruv) maydonga `aria-label` bering.
- **Telefon, karta raqami, sana** kabi qat'iy formatlar uchun
  [`MaskedInput`](./masked-input.mdx) qulayroq.
- **`placeholder` label o'rnini bosmaydi** — u yozish boshlanishi bilan yo'qoladi. Misol
  qiymat uchun ishlating: "90 123 45 67".

## Ikonkalar, prefix va suffix

`leftIcon` / `rightIcon` — bezak ikonkalari (`aria-hidden`). `prefix` / `suffix` — maydon
ichidagi doimiy matn, ajratuvchi chiziq bilan: mamlakat kodi, valyuta, domen.

## Tozalash (`clearable`)

`clearable` bo'lsa va maydonda qiymat bo'lsa, ✕ tugmasi chiqadi. `Esc` ham tozalaydi. Tozalash
oddiy `input` hodisasi orqali o'tadi — boshqariladigan rejimda `onChange` ham chaqiriladi,
qo'shimcha ravishda `onClear`.

### Data atributlari

Atributlar tashqi konteynerda (`data-slot="input"`):

| Atribut         | Qiymat                      |
| --------------- | --------------------------- |
| `data-size`     | `sm` · `md` · `lg`          |
| `data-invalid`  | Xato holatida mavjud        |
| `data-disabled` | `disabled` bo'lganda mavjud |
| `data-readonly` | `readOnly` bo'lganda mavjud |

## Accessibility

- **Native `<input>`** — brauzerning avtoto'ldirish, tekshiruv va klaviatura xatti-harakati
  saqlanadi.
- **Field bilan** `id`, `aria-describedby`, `aria-invalid` va `aria-required` avtomatik ulanadi.
- **Fokus halqasi** konteynerda (`:focus-within`) — ikonka va prefix ham halqa ichida qoladi.
- **`Esc`** qiymatni tozalaydi (faqat `clearable` va maydon bo'sh bo'lmasa). Bo'sh maydonda
  hodisa yuqoriga o'tadi — masalan, `Dialog` yopiladi.
- **Tozalash tugmasi** `Tab` tartibida yo'q (`tabIndex={-1}`) — klaviaturada uning o'rnini `Esc`
  bosadi. Parol tugmasi esa fokuslanadi va `aria-label` i holatga qarab almashadi.
- **Ikonkalar** `aria-hidden` — ma'noli bo'lsa, uni label yoki `aria-label` da yozing.
