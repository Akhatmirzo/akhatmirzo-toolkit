## Import

```tsx
import { Button } from '@akhatmirzo/ui';
```

## When to use

- **For actions** — saving, submitting, opening a dialog. Navigation needs a real link: pass an
  `<a>` with `asChild` (see the example below).
- **One `primary` per view.** Reserve it for the action you expect the user to take. Other
  buttons should be `soft` (the default), `outline` or `ghost`.
- **`danger` only for destructive actions:** deleting, anything that can't be undone. Usually
  paired with `confirm()`.
- **Icon only?** Use [`IconButton`](./icon-button.mdx) instead of `Button` — it makes
  `aria-label` required.
- **Label with a verb:** "Save", "Send", "Delete" — not "OK" or "Yes".

## Variants

`variant` sets the look and the visual weight. The default is `soft`.

| Variant   | Use it for                                     |
| --------- | ---------------------------------------------- |
| `primary` | The main action — at most one per view         |
| `soft`    | Secondary actions (default)                    |
| `outline` | Neutral, bordered — "Cancel", filters          |
| `ghost`   | No background — inside toolbars and table rows |
| `danger`  | Delete and other destructive actions           |
| `link`    | A button that looks like text, no padding      |

## Sizes

Three sizes — 32, 40 and 48px. They match `Input` and `Select`, so controls line up in a row.
The `sm` size gets an invisible hit area extended to 40px.

## Icons

`leftIcon` and `rightIcon` take any `ReactNode`. The icon size follows the button size:
16 / 18 / 20px. Icons are hidden from screen readers (`aria-hidden`).

## Loading and disabled

While `loading`, the label keeps its place (the width doesn't jump), a spinner sits on top and
clicks are ignored. Click the first button to try it.

<ComponentPreview name="button/loading" />

<Callout title="loading vs. disabled">
  A `disabled` button leaves the tab order and can't be clicked. A `loading` button **stays**
  focusable, so keyboard users don't lose their place — only clicks are blocked.
</Callout>

## As a link (`asChild`)

With `asChild`, `Button` renders its child instead of its own `<button>` — the styles come from
the button, the element is your `<a>`. In Next.js you can pass `<Link>` the same way.

<ComponentPreview name="button/as-child" />

```tsx
import Link from 'next/link';

<Button asChild variant="primary">
  <Link href="/orders">Go to orders</Link>
</Button>;
```

### Data attributes

State is exposed through `data-*` attributes, so you can hook your own styles onto them:

| Attribute       | Value                                                        |
| --------------- | ------------------------------------------------------------ |
| `data-variant`  | `primary` · `soft` · `outline` · `ghost` · `danger` · `link` |
| `data-size`     | `sm` · `md` · `lg`                                           |
| `data-disabled` | Present when `disabled`                                      |
| `data-loading`  | Present when `loading`                                       |

Need the button look on another element? `buttonVariants` is exported too:

```tsx
import { buttonVariants } from '@akhatmirzo/ui';

<label className={buttonVariants({ variant: 'outline', size: 'sm' })}>Choose a file</label>;
```

## Accessibility

- **Native element.** By default it renders a real `<button type="button">`, so it never
  submits a form by accident and responds to `Enter` and `Space`.
- **The focus ring** only shows up for keyboard focus (`:focus-visible`).
- **Loading.** `loading` sets `aria-busy="true"` and `aria-disabled="true"` and keeps the button
  focusable. Since many screen readers ignore `aria-busy`, a hidden `aria-live` region announces
  "Yuklanmoqda" — change the text with `labels.loading` (for example, `'Loading'` in an English
  app).
- **Icons and the spinner** are `aria-hidden`, so screen readers read only the label.
- **`asChild` + `disabled`.** An `<a>` has no `disabled` attribute, so the button sets
  `aria-disabled="true"` and `tabIndex={-1}` and cancels the click.
- **Small buttons.** `size="sm"` looks 32px tall but has a 40px hit area — easy to tap with a
  finger.
