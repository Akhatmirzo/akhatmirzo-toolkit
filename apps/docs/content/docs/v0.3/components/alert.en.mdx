## Import

```tsx
import { Alert } from '@akhatmirzo/ui';
```

## When to use

- **For messages that should stay on the page** — an expiring subscription, a failed payment, a
  form-level problem. An alert doesn't disappear by itself; it sits in the content flow.
- **For short, temporary feedback** — "Saved", "Copied" — use a [`Toast`](./toast.mdx) instead.
- **Match the color to the meaning:** `danger` for errors, `warning` for warnings, `success` for
  success, `info` for information. Let the title state the problem — don't rely on color alone.
- **One action is enough** — "Try again", "Pay now". If you need more, consider a
  [`Dialog`](./dialog.mdx).
- **Your app controls dismissal** — remove the alert yourself in `onClose`.

## Colors

`color`: `info` (default), `neutral`, `primary`, `success`, `warning` and `danger`. Each color has
a matching built-in icon: ⓘ, ✓, △, ⊗. Pass your own with `icon`, or `icon={false}` for none.

## Variants

`variant`: `soft` (default) is a light background, `outline` is a colored border on the surface
color, and `solid` is a strong background that draws the most attention.

## Action and close

`action` renders on the right (it drops below the text on narrow screens). Pass `onClose` to show
a ✕ button.

## Banner

`banner` is for the top of a page: square corners, a bottom border only and centered content.

### Data attributes

On the root: `data-color`, `data-variant` and `data-banner` (in banner mode). `alertVariants` is
exported too, so you can apply the styles to another element.

## Accessibility

- **The role follows the color:** `danger` and `warning` get `role="alert"` (read out right away),
  the rest get `role="status"` (read politely). Pass your own `role` if you need to.
- **Color is never the only signal** — the icon and title also tell the type. The icon is
  `aria-hidden`.
- **The ✕ button** is a real `<button>`: it's reachable with `Tab` and works with `Enter` / `Space`.
  Change its label with `labels.close`.
- **Alerts present on page load** may not be announced — `role="alert"` mainly helps with messages
  that appear later.
