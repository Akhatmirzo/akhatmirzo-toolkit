## Import

```tsx
import { DropdownMenu } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Bir obyekt ustidagi amallar** — jadval qatoridagi "⋯" tugmasi, kartochka menyusi, profil
  menyusi.
- **Ko'rinish sozlamalari** — `CheckboxItem` (qaysi ustunlar ko'rinsin) va `RadioGroup`
  (saralash tartibi).
- **Qiymat tanlash uchun emas.** Forma maydoni kerak bo'lsa — [`Select`](./select.mdx) yoki
  [`Combobox`](./combobox.mdx): ular qiymatni saqlaydi va formaga yuboradi.
- **Xavfli amal** (`variant="danger"`) menyuning oxirida, ajratgichdan keyin tursin; kerak
  bo'lsa, [`confirm()`](./dialog.mdx) bilan tasdiqlating.
- **Ichki menyuni bir darajadan chuqur qilmang** — klaviatura bilan ham, telefonda ham
  noqulay.

## Belgilash elementlari

`CheckboxItem` — `checked` / `onCheckedChange`, `RadioGroup` — `value` / `onValueChange`
(yoki boshqarilmaydigan `defaultValue`). Tanlovdan keyin menyu yopiladi; bir nechtasini ketma-ket
belgilash uchun `onSelect` ichida `e.preventDefault()` chaqiring.

## Ichki menyu

`Sub` ichida `SubTrigger` va `SubContent`. Sichqoncha bilan ustiga borganda, klaviatura bilan
`→` bosganda ochiladi.

## Profil menyusi: Label, Group va havola

`Label` va `Group` menyuni bo'limlarga ajratadi. `Item` ga `asChild` berib, `<a>` (yoki Next.js
`Link`) ni element sifatida ishlatasiz — ikonka va yorliq havolaning ichiga qo'shiladi.
`align="end"` panelni triggerning o'ng chetiga tekislaydi.

<ComponentPreview name="dropdown-menu/profile" />

```tsx
<DropdownMenu.Item asChild icon={<Settings />}>
  <Link href="/sozlamalar">Sozlamalar</Link>
</DropdownMenu.Item>
```

<Callout title="shortcut — faqat yorliq">
  `shortcut={['mod', 'E']}` menyuda `⌘E` (Windows'da `Ctrl E`) ko'rsatadi va `aria-keyshortcuts`
  qo'yadi, lekin tugma bosilishini **ushlamaydi**. Qisqa yo'lning o'zini
  [`useHotkeys`](../hooks.mdx) bilan ulang.
</Callout>

## Holatlar

`disabled` element bosilmaydi va klaviatura navigatsiyasida o'tkazib yuboriladi. Trigger ham
`disabled` bo'lishi mumkin. `open` + `onOpenChange` bilan menyuni koddan ochasiz.

### Sub, SubTrigger, SubContent

`Sub` — `open`, `defaultOpen`, `onOpenChange`. `SubTrigger` — `icon` va `disabled`.
`SubContent` — `sideOffset` (standart `8`), `alignOffset` (`-6`), `collisionPadding` (`8`),
`loop` (`true`) va `container`.

### Data atributlari

| Atribut            | Qayerda            | Qiymat                              |
| ------------------ | ------------------ | ----------------------------------- |
| `data-state`       | trigger, panel     | `open` · `closed`                   |
| `data-variant`     | element            | `default` · `danger`                |
| `data-highlighted` | element            | klaviatura yoki sichqoncha ustida   |
| `data-disabled`    | element            | o'chirilganda mavjud                |
| `data-state`       | Checkbox/RadioItem | `checked` · `unchecked`             |
| `data-side`        | panel              | `top` · `right` · `bottom` · `left` |

## Klaviatura

| Tugma                   | Harakat                                            |
| ----------------------- | -------------------------------------------------- |
| `Enter` / `Space` / `↓` | Trigger fokusda — ochadi, fokus birinchi elementga |
| `↓` / `↑`               | Elementlar bo'ylab yurish (aylanma)                |
| `Home` / `End`          | Birinchi / oxirgi element                          |
| Harf                    | Shu harf bilan boshlanadigan elementga sakrash     |
| `→` / `←`               | Ichki menyuni ochish / yopish                      |
| `Enter` / `Space`       | Tanlash va yopish                                  |
| `Esc`                   | Yopish, fokus triggerga qaytadi                    |

## Accessibility

- **Rollar.** Panel — `role="menu"`, elementlar — `menuitem`, `menuitemcheckbox`,
  `menuitemradio`; trigger `aria-haspopup="menu"` va `aria-expanded` oladi. Asosida Radix
  DropdownMenu.
- **Qisqa yo'llar.** `shortcut` berilsa, elementga `aria-keyshortcuts` qo'yiladi (`mod` —
  macOS'da `Meta`, boshqa tizimlarda `Control`). Ko'rinadigan `Kbd` esa ekran o'quvchidan
  yashirin.
- **Ikonkalar** `aria-hidden`.
- **Ikonka trigger.** `IconButton` trigger bo'lsa, `aria-label` yozing ("Ko'proq amallar").
- **Fokus.** Ochilganda fokus menyuga o'tadi, yopilgach triggerga qaytadi.
