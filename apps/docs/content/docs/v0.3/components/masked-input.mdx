## Import

```tsx
import { CardInput, MaskedInput, MoneyInput, PhoneInput } from '@akhatmirzo/ui';
```

To'rt komponentning umumiy qoidasi: **ichki qiymat — toza, ko'rinish — formatlangan.** Ekranda
"(90) 123-45-67", `onValueChange` da esa `"901234567"`. Serverga yuborish, saqlash va tekshirish
uchun ortiqcha belgilarni tozalash shart emas.

| Komponent     | Ko'rinish                   | Qiymat (`value`)     |
| ------------- | --------------------------- | -------------------- |
| `PhoneInput`  | `+998` (90) 123-45-67       | `"901234567"`        |
| `MoneyInput`  | 1 250 000 so'm              | `1250000` (`number`) |
| `CardInput`   | 8600 1234 1234 1234 UZCARD  | `"8600123412341234"` |
| `MaskedInput` | AB 1234567 (`"AA 9999999"`) | `"AB1234567"`        |

## Qachon ishlatish

- **Format qat'iy bo'lgan ma'lumot uchun** — telefon, karta, pasport, avtomobil raqami.
  Foydalanuvchi ajratuvchilarni o'zi yozmaydi, xato qilish imkoni kamayadi.
- **Pul summasi uchun** — `MoneyInput`: minglik ajratuvchi o'qishni osonlashtiradi, qiymat esa
  tayyor `number`.
- **Erkin matn uchun ishlatmang** — ism, manzil, izoh oddiy [Input](./input.mdx) bilan qoladi.
  Uzunligi o'zgaruvchan ma'lumotga niqob halal beradi.
- **Har doim label bering** — [Field](./field.mdx) ichida. Placeholder ("(90) 123-45-67") faqat
  namuna, label o'rnini bosmaydi.
- **Hamma narsa `Input` dan meros:** `size`, `invalid`, `clearable`, `leftIcon`, `disabled`,
  `readOnly` — barchasi xuddi [Input](./input.mdx) dagidek ishlaydi.

## Kursor sakramaydi

Formatlash paytida kursor joyida qoladi: raqamni o'rtadan o'chirsangiz yoki qo'shsangiz ham u
"oxiriga qochmaydi". `Backspace` doimiy belgini (`-`, bo'sh joy, nuqta) emas, undan oldingi
raqamni o'chiradi — `Delete` ham xuddi shunday, oldinga qarab.

## PhoneInput

O'zbekiston raqami: `+998` — o'chirib bo'lmaydigan prefiks, foydalanuvchi faqat 9 raqam yozadi.
"+998 90 123 45 67" ni nusxalab joylasangiz ham to'g'ri tushadi. Operator kodi tekshiriladi (33,
50, 55, 77, 88, 90, 91, 93, 94, 95, 97, 98, 99) — noto'g'ri kodda maydon avtomatik `invalid`
bo'ladi.

<ComponentPreview name="archive/v0.3/masked-input/phone" align="start" />

`onValueChange` ikkinchi argumentda tafsilotlarni beradi: `{ valid, operator, complete }`. Xuddi
shu ma'lumotni komponentdan tashqarida `getPhoneDetails(value)` bilan olasiz — masalan forma
tekshiruvida.

```tsx
import { getPhoneDetails } from '@akhatmirzo/ui';

getPhoneDetails('901234567'); // { valid: true, operator: '90', complete: true }
getPhoneDetails('121234567'); // { valid: false, operator: null, complete: true }
```

## MoneyInput

Minglik ajratuvchi — bo'sh joy, o'ngda valyuta (standart — "so'm"). Qiymat — `number | null`.
Mobilda raqamli klaviatura ochiladi (`decimals` bo'lsa — kasr nuqtasi bilan).

<ComponentPreview name="archive/v0.3/masked-input/money" align="start" />

- `decimals` — kasr raqamlari soni (standart `0`). Vergul bilan yozilsa ham nuqtaga aylanadi.
- `max` — undan katta qiymatni yozib bo'lmaydi (belgi qabul qilinmaydi).
- `min` — kichik qiymat maydondan chiqqanda (`blur`) `min` ga tenglashtiriladi.
- `currency={null}` — valyuta ko'rsatilmaydi; `currency="$"` yoki istalgan `ReactNode`.

## Summa so'zlar bilan

`showWords` — summa maydon ostida so'z bilan yoziladi: "Bir million ikki yuz ellik ming soʻm".
Shartnoma, hisob-faktura va to'lov formalarida raqamni tekshirishga yordam beradi. Matn
`@akhatmirzo/core` dagi `moneyToWords` bilan yasaladi va yozish bilan birga yangilanadi.

<ComponentPreview name="archive/v0.3/masked-input/money-words" align="start" />

- `showWords={{ script: 'cyrillic' }}` — kirillda. `script` berilmasa,
  [ScriptProvider](./script.mdx) dagi alifbo olinadi (provider bo'lmasa — lotin).
- `showWords={{ formal: true }}` — rasmiy uslub: "bir yuz", "bir ming".
- [Field](./field.mdx) ichida so'zlar `description` dan keyin, maydon ostida chiqadi va
  `aria-describedby` ga qo'shiladi. Matn `aria-live="polite"` hududida — ekran o'quvchi yangi
  summani o'qiydi.

## CardInput

Bank kartasi: 4 tadan guruh, o'ngda brend belgisi — **UZCARD** (8600), **HUMO** (9860), **VISA**
(4) va Mastercard (51–55, 2221–2720). 16 raqam kiritilganda Luhn tekshiruvi o'tkaziladi; o'tmasa —
maydon `invalid`.

<ComponentPreview name="archive/v0.3/masked-input/card" align="start" />

Brend belgisi rasmiy logo emas — semantik tokenlardagi neytral matnli belgi (dark mode'da ham
o'qiladi). Rasmiy logo kerak bo'lsa, `renderBrand` bilan o'zingiz chizing:

```tsx
import { CardInput } from '@akhatmirzo/ui';

<CardInput renderBrand={(brand) => <img src={`/cards/${brand}.svg`} alt="" className="h-5" />} />;
```

`getCardDetails(value)` — `{ brand, complete, valid }`; `CardBrandMark` komponenti ham eksport
qilinadi (`<CardBrandMark brand="humo" />`).

## O'z niqobingiz

`MaskedInput` — umumiy niqob. Belgilar: `9` — raqam, `A` — harf, `*` — istalgan belgi (bo'sh
joydan tashqari). Qolgan har qanday belgi — doimiy, foydalanuvchi uni yozmaydi. `uppercase` —
harflarni avtomatik katta qiladi.

<ComponentPreview name="archive/v0.3/masked-input/custom-mask" align="start" />

`onValueChange(value, { formatted, complete })` — `complete` barcha o'rinlar to'lganini bildiradi.
Ildiz elementda `data-mask` atributi bor.

## Formada

`name` bersangiz, formaga **toza** qiymatli yashirin `<input>` qo'shiladi — `FormData` da
`"901234567"`, `"1250000"` kabi qiymat keladi, formatlangan matn emas.

```tsx
<form action="/api/order">
  <PhoneInput name="phone" required />
  <MoneyInput name="amount" />
</form>
```

## Accessibility

- **Native `<input type="text">`** — ekran o'quvchi formatlangan matnni o'qiydi, tahrirlash
  odatdagidek ishlaydi.
- **Mobil klaviatura** turiga mos: `PhoneInput` — `inputMode="tel"`, `CardInput` va
  `MoneyInput` — `numeric` (`decimals` bilan — `decimal`).
- **Avtoto'ldirish:** `PhoneInput` — `autoComplete="tel-national"`, `CardInput` —
  `autoComplete="cc-number"`. `MaskedInput` da avtoto'ldirish o'chiq (`off`), imlo tekshiruvi ham.
- **Xato holati** (`validateOperator`, `validateLuhn`) `aria-invalid` sifatida beriladi. Xato
  sababini matn bilan `Field` ning `error` prop'ida ko'rsating — rang yetarli emas.
- **Valyuta va karta brendi** dekorativ (`aria-hidden`) — summa uchun label'ga valyutani yozing
  ("Summa, so'm"), agar u muhim bo'lsa.
