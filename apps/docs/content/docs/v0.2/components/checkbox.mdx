## Import

```tsx
import { Checkbox } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **"Saqlash" tugmasi bor formalarda** — tanlov forma yuborilganda kuchga kiradi. Darhol ta'sir
  qiladigan sozlama uchun [`Switch`](./switch.mdx) ishlating.
- **Bir nechta mustaqil tanlov uchun** — bildirishnoma kanallari, filtrlar. Bir nechtadan faqat
  bittasi tanlanadigan bo'lsa — [`RadioGroup`](./radio-group.mdx).
- **Rozilik uchun** — "Shartlarga roziman". Majburiy bo'lsa, [`Field`](./field.mdx) dagi
  `required` va `error` bilan.
- **Label'ni ijobiy shaklda yozing:** "Xabarnomalarni yuborish", "Xabarnomalarni yubormaslik"
  emas.

## O'lchamlar

`sm` — 16px, `md` (standart) — 20px. Ikkalasida ham ko'rinmas bosish maydoni katakdan kattaroq.

## Izoh bilan

`description` label ostida kichikroq, xira matnda chiqadi va ekran o'quvchiga
`aria-describedby` orqali bog'lanadi.

<ComponentPreview name="archive/v0.2/checkbox/description" />

## Qisman tanlangan holat

`checked="indeterminate"` — "−" belgisi. Odatda "hammasini tanlash" katakchasida: bolalarning
bir qismi tanlangan bo'lsa. `onCheckedChange` faqat `boolean` qaytaradi — qisman holatni o'zingiz
hisoblaysiz.

<ComponentPreview name="archive/v0.2/checkbox/select-all" />

## Holatlar

`disabled` — katak va label xiralashadi, bosilmaydi. `invalid` — chegara qizil, input'da
`aria-invalid`.

<ComponentPreview name="archive/v0.2/checkbox/states" />

## Field bilan

`Field` xato va izohni katakchaga ulaydi; `error` bo'lsa, `invalid` avtomatik yoqiladi. Katakni
belgilab ko'ring.

### Data atributlari

Ildiz `<label>` da:

| Atribut         | Qiymat                                    |
| --------------- | ----------------------------------------- |
| `data-state`    | `checked` · `unchecked` · `indeterminate` |
| `data-size`     | `sm` · `md`                               |
| `data-disabled` | `disabled` bo'lganda mavjud               |
| `data-invalid`  | Xato holatida mavjud                      |

## Accessibility

- **Native `<input type="checkbox">`** — `Space` bilan almashtiriladi, formaga oddiy checkbox
  kabi yuboriladi, brauzer tekshiruvi (`required`) ishlaydi.
- **Label bosilganda ham** belgilanadi — butun komponent `<label>` ichida.
- **Qisman holat** ekran o'quvchiga `aria-checked="mixed"` bilan aytiladi.
- **Fokus halqasi** faqat klaviatura bilan kelganda chiqadi.
- **Label'siz katakcha** (masalan, jadval qatorida) uchun `aria-label` bering.
