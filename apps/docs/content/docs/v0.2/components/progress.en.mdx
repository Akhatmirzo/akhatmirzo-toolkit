## Import

```tsx
import { Progress, ProgressCircle } from '@akhatmirzo/ui';
```

## When to use

- **For tasks with a known length** — file uploads, exports, profile completion.
- **When you can't tell how long it takes**, pass `value={null}` (indeterminate).
- **For short waits** (under a second) you don't need a progress bar — a
  [`Spinner`](./spinner.mdx) inside the button is enough.
- **Use the circle** in cards, next to avatars or where space is tight; **use the bar** in lists
  and forms.
- **Show the number too** (`showValue`) so people see the exact value.

## Indeterminate

When `value` is missing or `null`, a segment slides across the bar and the circle spins. With
reduced motion enabled (`prefers-reduced-motion`), only a soft pulse remains.

<ComponentPreview name="archive/v0.2/progress/indeterminate" align="start" />

## Colors and sizes

`color`: `primary` (default), `success`, `warning` and `danger`. `size`: `sm` is a 4px bar, `md`
8px and `lg` 12px.

<ComponentPreview name="archive/v0.2/progress/colors-sizes" />

## ProgressCircle

Circle sizes: `sm` is 24px, `md` 40px and `lg` 64px. `showValue` puts the value in the middle
(not on `sm` — there's no room). On the circle, `label` isn't visible; it becomes the accessible
name.

### Data attributes

On the root: `data-state` (`indeterminate` · `loading` · `complete`), `data-color` and
`data-size`.

## Accessibility

- **`role="progressbar"`** with `aria-valuemin`, `aria-valuemax`, `aria-valuenow` and
  `aria-valuetext` (the `formatValue` result) set for you.
- **When indeterminate**, `aria-valuenow` and `aria-valuetext` are omitted, so screen readers treat
  it as busy.
- **A name is required:** pass `label`, or set `aria-label` / `aria-labelledby` yourself. On the bar
  `label` is linked with `aria-labelledby`; on the circle a text `label` becomes `aria-label`.
- **The visible value** is `aria-hidden` — it's already read via `aria-valuetext`.
- **With reduced motion**, sliding and spinning stop and only a pulse remains.
