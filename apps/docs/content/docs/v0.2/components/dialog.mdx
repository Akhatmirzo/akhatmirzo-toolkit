## Import

```tsx
import { Dialog, ConfirmDialog, ConfirmProvider, confirm } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Diqqatni bitta vazifaga qaratish kerak bo'lsa** — qisqa forma, tafsilotlarni tahrirlash,
  muhim ogohlantirish. Foydalanuvchi oynani yopmaguncha sahifa bilan ishlay olmaydi.
- **Xavfli amalni tasdiqlash** — `confirm()` yoki `ConfirmDialog`. Bitta qator kod bilan
  `true` / `false` javob olasiz.
- **Uzun forma yoki filtrlar** uchun yon panel — [`Drawer`](./drawer.mdx) qulayroq: sahifa
  konteksti ko'rinib turadi.
- **Kichik, bog'lanmagan kontent** (filtr, rang tanlash) uchun modal kerak emas —
  [`Popover`](./popover.mdx) oling.
- **Natija haqida xabar** ("Saqlandi") uchun oyna ochmang — [`toast()`](./toast.mdx) yetarli.

## Tuzilishi

`Dialog` — holatni boshqaradi (`open`, `defaultOpen`, `onOpenChange`). Qolgan qismlar:

| Qism             | Vazifasi                                                          |
| ---------------- | ----------------------------------------------------------------- |
| `Dialog.Trigger` | Ochuvchi element. `asChild` bilan o'zingizning tugmangizni bering |
| `Dialog.Content` | Oynaning o'zi: fon, sarlavha, izoh, ✕ tugmasi, fokus tuzog'i      |
| `Dialog.Footer`  | Pastki tugmalar qatori — o'ngga tekislangan, 8px oraliq           |
| `Dialog.Close`   | Bosilganda oynani yopadigan element (`asChild` bilan)             |

```tsx
<Dialog open={open} onOpenChange={setOpen}>
  <Dialog.Trigger asChild>
    <Button>Ochish</Button>
  </Dialog.Trigger>
  <Dialog.Content title="Profilni tahrirlash" description="O'zgarishlar darhol saqlanadi.">
    {/* forma */}
    <Dialog.Footer>
      <Dialog.Close asChild>
        <Button>Bekor qilish</Button>
      </Dialog.Close>
      <Button variant="primary">Saqlash</Button>
    </Dialog.Footer>
  </Dialog.Content>
</Dialog>
```

`title` — majburiy: ekran o'quvchi oynani shu nom bilan e'lon qiladi. Ko'rinmasligi kerak bo'lsa,
`hideTitle` qo'ying, lekin olib tashlamang.

## O'lchamlar

`size` oyna kengligini belgilaydi: `sm` — 400px, `md` — 520px (standart), `lg` — 640px, `xl` —
800px, `full` — butun ekran. Balandlik ekrandan 32px kam bo'lishi mumkin, kontent uzun bo'lsa
oyna ichida scroll paydo bo'ladi.

## Sozlamalar

- `dismissible={false}` — tashqariga bosish oynani yopmaydi (`Esc` ishlayveradi).
- `closeButton={false}` — o'ng yuqoridagi ✕ tugmasini olib tashlaydi.
- `hideTitle` — sarlavhani ko'rinmas qiladi, ekran o'quvchi uni baribir o'qiydi.
- `mobileSheet={false}` — telefonda (640px dan tor ekranda) ham oyna markazda qoladi. Standart
  holatda u pastdan chiqadigan sheet'ga aylanadi.

## Tasdiqlash: confirm()

`confirm()` — imperativ API: oynani ochadi va `Promise<boolean>` qaytaradi. "Tasdiqlash" —
`true`, "Bekor qilish", `Esc` yoki tashqariga bosish — `false`.

<ComponentPreview name="archive/v0.2/dialog/confirm" />

```tsx
const ok = await confirm({
  title: "Buyurtma o'chirilsinmi?",
  description: "Bu amalni qaytarib bo'lmaydi.",
  confirmText: "O'chirish",
  variant: 'danger',
});
if (ok) await deleteOrder(id);
```

- `variant: 'danger'` — tasdiqlash tugmasi qizil, **dastlabki fokus "Bekor qilish" da**:
  foydalanuvchi `Enter` ni tasodifan bosib, ma'lumotni o'chirib yubormaydi.
- `onConfirm` Promise qaytarsa — tugma `loading` holatiga o'tadi, oyna javob kelguncha yopilmaydi
  (`Esc` va tashqariga bosish ham ishlamaydi). Promise xato bilan tugasa, oyna ochiq qoladi —
  foydalanuvchi qayta urinadi yoki bekor qiladi.

<Callout title="ConfirmProvider shart" type="warn">
  `confirm()` ishlashi uchun ilovada bir marta `<ConfirmProvider />` turishi kerak. U bo'lmasa,
  `confirm()` "ilovada `<ConfirmProvider />` topilmadi" xatosi bilan rad etiladi.
</Callout>

```tsx title="app/providers.tsx"
'use client';

import { ConfirmProvider } from '@akhatmirzo/ui';
import type { ReactNode } from 'react';

export function Providers({ children }: { children: ReactNode }) {
  return <ConfirmProvider>{children}</ConfirmProvider>;
}
```

`ConfirmProvider` ilovani o'rab olishi ham, yonida yolg'iz turishi ham mumkin. Uning `labels`
prop'i barcha `confirm()` oynalari uchun standart tugma matnlarini o'rnatadi:
`labels={{ confirm: 'Confirm', cancel: 'Cancel' }}`.

| `data-state` | panel   | `open` · `closed`                             |

## Klaviatura

| Tugma         | Harakat                                                 |
| ------------- | ------------------------------------------------------- |
| `Tab`         | Oyna ichidagi keyingi element (fokus oynadan chiqmaydi) |
| `Shift + Tab` | Oldingi element                                         |
| `Esc`         | Oynani yopadi, fokus ochgan elementga qaytadi           |

## Accessibility

- **Rol va nom.** Panel — `role="dialog"` (`confirm()` va `ConfirmDialog` da —
  `role="alertdialog"`), `aria-labelledby` sarlavhaga, `aria-describedby` izohga ulanadi. Izoh
  bo'lmasa, `aria-describedby` umuman qo'yilmaydi.
- **Fokus tuzog'i.** Ochiq paytda fokus oyna ichida aylanadi, sahifaning qolgan qismi
  ekran o'quvchidan yashiriladi va scroll qilinmaydi.
- **Dastlabki fokus:** `[data-autofocus]` → birinchi maydon (`input`, `textarea`, `select`) →
  birinchi tugma (✕ dan tashqari) → panelning o'zi.
- **Fokusni qaytarish.** Yopilgach fokus `Dialog.Trigger` ga qaytadi. Trigger bo'lmasa
  (boshqariladigan rejim yoki `confirm()`), oyna ochilishidan oldin fokusda bo'lgan elementga
  qaytadi.
- **✕ tugmasi** "Yopish" nomini oladi — `labels.close` bilan o'zgartiriladi.
- **Kamroq harakat.** `prefers-reduced-motion` yoqilgan bo'lsa, siljish o'rniga faqat shaffoflik
  animatsiyasi ishlaydi.
