## Import

```tsx
import { VirtualList, type VirtualListHandle } from '@akhatmirzo/ui';
```

Yuqoridagi ro'yxatda 10 000 ta yozuv, lekin DOM'da bir vaqtda faqat 20 ga yaqin qator bor:
ko'rinib turganlar va ikki tomonda bir oz zaxira (`overscan`). Scroll paytida qatorlar qayta
ishlatiladi ([TanStack Virtual](https://tanstack.com/virtual) asosida).

## Qachon ishlatish

- **Yuzlab va minglab elementli ro'yxatlar** — jurnal (log), xabarlar, bildirishnomalar, katalog.
  100 tagacha element bo'lsa, oddiy ro'yxat yetarli va soddaroq.
- **Cheksiz yuklash (infinite scroll)** — `onEndReached` va `loadingMore` bilan, sahifalash
  tugmalarisiz.
- **Jadval kerak bo'lsa** — ustunlar, saralash, filtr bilan — [DataTable](./data-table.mdx) ning
  `virtual` rejimini ishlating.
- **Balandlikni aniq bering:** `height` majburiy — virtual ro'yxat o'z scroll konteyneriga ega
  bo'lishi kerak.
- **Har bir qatorga barqaror kalit bering** (`getItemKey`) — ro'yxat o'zgarganda (qo'shish,
  o'chirish) qatorlar adashmaydi.

## Qatorga o'tish

`ref` — DOM element emas, boshqaruv obyekti (`VirtualListHandle`): `scrollToIndex`,
`scrollToOffset`, `measure` va scroll konteyneri — `element`. Yuqoridagi demoda raqam yozib,
`Enter` bosing.

```tsx
const ref = useRef<VirtualListHandle>(null);

ref.current?.scrollToIndex(4999, { align: 'start' }); // 5000-qator tepada
ref.current?.scrollToOffset(0); // boshiga
ref.current?.element?.focus(); // DOM element
```

## Har xil balandlik

Qatorlar balandligi har xil bo'lsa (xabarlar, izohlar) — `dynamic` bering: har bir qator
chizilgach haqiqiy o'lchami olinadi. `estimateSize` bu holda faqat boshlang'ich taxmin; u haqiqiy
o'rtachaga qanchalik yaqin bo'lsa, scroll paneli shunchalik silliq.

## Cheksiz yuklash

`onEndReached` — oxiriga `endReachedThreshold` (standart 5) qator qolganda chaqiriladi, har bir
ro'yxat uzunligi uchun **bir marta**. Yuklash paytida `loadingMore` bering: pastda Spinner qatori
chiqadi va `onEndReached` qayta chaqirilmaydi. Agar yuklash xato bilan tugasa (`loadingMore` false
bo'ldi, lekin uzunlik o'zgarmadi), keyingi scroll'da yana chaqiriladi — qayta urinish o'zi
bo'ladi.

## Klaviatura

Scroll konteyneri `Tab` bilan fokuslanadi (fokus halqasi ko'rinadi). Fokusda brauzerning odatiy
scroll tugmalari ishlaydi: `↑ ↓`, `PageUp` / `PageDown`, `Home` / `End`, `Space`.

## Accessibility

- **Ro'yxat semantikasi:** ichki element — `role="list"`, har bir qator — `role="listitem"`.
  `aria-setsize` (jami) va `aria-posinset` (o'rni) bilan — ekran o'quvchi "10 000 dan 5 000-element"
  deb o'qiydi, garchi DOM'da 20 ta qator bo'lsa ham.
- **Nom bering:** `aria-label` yoki `aria-labelledby` — ro'yxatga beriladi.
- **Yuklanish:** `loadingMore` paytida ro'yxatda `aria-busy`, Spinner'ning yashirin matni
  (`labels.loadingMore`) o'qiladi.
- **Qator ichidagi interaktiv elementlar** (tugma, havola) odatdagidek ishlaydi, lekin ekrandan
  tashqaridagi qatorlar DOM'da yo'q — sahifa ichidagi qidiruv (`Ctrl+F`) ularni topmaydi. Bunday
  holatda o'z qidiruv maydoningizni qo'shing.
