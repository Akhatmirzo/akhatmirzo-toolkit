## Import

```tsx
import { SegmentedControl } from '@akhatmirzo/ui';
```

## When to use

- **View modes** — "Grid / List / Map". The choice applies immediately.
- **Filters or periods** — "Day / Week / Month", "All / Paid / Unpaid".
- **Keep it to 2–5 short options.** For more or longer ones use a [`Select`](./select.mdx) or a
  [`RadioGroup`](./radio-group.mdx).
- **Not for on/off** — a two-state setting is a [`Switch`](./switch.mdx).

## How it differs from Tabs

They can look the same, but they do different jobs:

|              | `Tabs`                                | `SegmentedControl`                        |
| ------------ | ------------------------------------- | ----------------------------------------- |
| What it does | Switches content **panels**           | Picks a **value** (filter, mode, period)  |
| Semantics    | `tablist` / `tab` / `tabpanel`        | `radiogroup` / `radio`                    |
| Result       | A different section of the page shows | The same content is refiltered or redrawn |
| Forms        | No                                    | Submits a value with `name`               |

Rule of thumb: if the choice reveals **different content**, use [`Tabs`](./tabs.mdx); if **the same
content** changes how it looks or what it shows, use `SegmentedControl`.

## Sizes

`size` — `sm` (32px), `md` (40px, default), `lg` (48px). The heights match [`Button`](./button.mdx)
and `Input`, so they line up in one row.

## Icons

`icon` adds an icon before the text. Icon-only items **require** an `aria-label` — TypeScript
enforces it.

<ComponentPreview name="archive/v0.2/segmented-control/icons" />

## Full width

`fullWidth` fills the container and splits it evenly between items. Handy in mobile forms.

<ComponentPreview name="archive/v0.2/segmented-control/full-width" align="start" />

## Controlled

`value` + `onValueChange` — you keep the selection. Clicking the selected item again doesn't clear
it: one value is always selected.

<ComponentPreview name="archive/v0.2/segmented-control/controlled" align="start" />

## Disabled

Pass `disabled` to the whole group or to a single `SegmentedControl.Item`. Disabled items can't be
clicked and the keyboard skips them.

## Keyboard

| Key               | Action                                                   |
| ----------------- | -------------------------------------------------------- |
| `Tab`             | Enter the group (on the selected item) and leave it      |
| `←` `↑` / `→` `↓` | Previous / next item — selected as soon as it gets focus |

## Accessibility

- **Roles.** The root is `role="radiogroup"`, each item `role="radio"` (`aria-checked`). Built on
  Radix RadioGroup: single selection with roving focus — the group is one `Tab` stop.
- **Name.** Give the group an `aria-label` ("Period"). Inside a [`Field`](./field.mdx) the label
  names the group and the description is linked through `aria-describedby`.
- **Icon-only items** need an `aria-label` (checked by TypeScript).
- **The indicator** is decorative — `aria-hidden`. It measures the selected item and slides over
  200ms; it re-measures when sizes change (window width, font loading). With
  `prefers-reduced-motion` it jumps without animating.
