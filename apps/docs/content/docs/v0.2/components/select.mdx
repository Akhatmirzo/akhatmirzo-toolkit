## Import

```tsx
import { Select } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **5–15 ta variantdan bittasini tanlash uchun** — viloyat, to'lov usuli, holat. Variantlar 3 ta
  yoki undan kam bo'lsa, [`RadioGroup`](./radio-group.mdx) qulayroq: hammasi birdan ko'rinadi.
- **Qidiruv kerak bo'lsa — [`Combobox`](./combobox.mdx).** `Select` ataylab qidiruvsiz qilingan;
  shaharlar yoki mahsulotlar kabi uzun ro'yxatlar uchun Combobox oling.
- **Bir nechta qiymat** tanlash uchun ham `Combobox` (`multiple`) kerak — `Select` faqat bitta
  qiymat qaytaradi.
- **Har doim nom bering:** [`Field`](./field.mdx) ichiga joylang yoki `aria-label` yozing.
- **Buyruqlar ro'yxati emas.** "Tahrirlash", "O'chirish" kabi amallar uchun
  [`DropdownMenu`](./dropdown-menu.mdx) bor.

## Guruhlar va ajratgich

`Select.Group` variantlarni sarlavha ostida jamlaydi, `Select.Separator` guruhlar orasiga chiziq
tortadi. Tanlangan variant yonida ✓ belgisi turadi.

<ComponentPreview name="select/groups" />

```tsx
<Select defaultValue="fer">
  <Select.Item value="tsh">Toshkent</Select.Item>
  <Select.Group label="Vodiy">
    <Select.Item value="and">Andijon</Select.Item>
    <Select.Item value="fer">Farg'ona</Select.Item>
  </Select.Group>
  <Select.Separator />
  <Select.Group label="Janub">
    <Select.Item value="qash">Qashqadaryo</Select.Item>
  </Select.Group>
</Select>
```

## O'lchamlar

Uch o'lcham — 32, 40 va 48px. Balandliklar `Input` va `Button` bilan bir xil, shuning uchun bir
qatorda tekis turadi. Panel kengligi trigger kengligiga teng; ro'yxat uzun bo'lsa, 320px dan
keyin ichida scroll paydo bo'ladi.

<ComponentPreview name="select/sizes" />

## Holatlar

`Field` ichida `disabled`, `error` va `required` o'zi ulanadi — `Select` ga qayta yozish shart
emas. `Field` siz ishlatsangiz, `invalid` va `disabled` ni to'g'ridan-to'g'ri bering. Bitta
variantni o'chirish uchun `Select.Item` ga `disabled` qo'ying — klaviatura uni o'tkazib yuboradi.

<ComponentPreview name="select/states" />

## Forma bilan

`name` berilsa, `Select` yashirin native `<select>` chizadi va qiymat `FormData` bilan birga
yuboriladi. Bo'sh qiymatni o'zingiz tekshirib, xabarni `Field` ning `error` prop'i orqali
ko'rsating.

<ComponentPreview name="select/form" align="start" />

## Dialog ichida

`Select` ni [`Dialog`](./dialog.mdx) yoki [`Drawer`](./drawer.mdx) ichida bemalol ishlatasiz:
panel modal qatlamida ekanini o'zi aniqlaydi va z-index'ini ko'taradi, shuning uchun ro'yxat
oyna ustida ochiladi. Hech narsa sozlash shart emas — tayyor misol Dialog sahifasidagi "Dialog
ichida Select va Combobox" bo'limida.

## RegionSelect

Toshkent shahri (`@akhatmirzo/core` dagi `UZ_REGIONS`). Qiymat — hudud `id` si (`'samarkand'`),
nomlar joriy alifboda: `script` prop'i yoki [ScriptProvider](./script.mdx) dan.

## Klaviatura

| Tugma                         | Harakat                                                 |
| ----------------------------- | ------------------------------------------------------- |
| `Enter` / `Space` / `↓` / `↑` | Trigger fokusda bo'lsa — panelni ochadi                 |
| `↓` / `↑`                     | Variantlar bo'ylab yurish (o'chirilganlari o'tkaziladi) |
| `Home` / `End`                | Birinchi / oxirgi variant                               |
| Harf                          | Shu harf bilan boshlanadigan variantga sakrash          |
| `Enter` / `Space`             | Tanlash va yopish                                       |
| `Esc`                         | Qiymatni o'zgartirmay yopish, fokus triggerga qaytadi   |

## Accessibility

- **Rollar.** Trigger — `role="combobox"` (`aria-expanded` bilan), panel — `listbox`, har bir
  variant — `option` (`aria-selected`). Asosida Radix Select turadi.
- **Field bilan bog'lanish.** `Field` ichida label, `description` va `error` matnlari triggerga
  `aria-labelledby` / `aria-describedby` orqali ulanadi; xatoda `aria-invalid="true"`,
  `required` da `aria-required="true"` qo'yiladi.
- **Fokus.** Panel ochilganda fokus tanlangan variantga o'tadi, yopilgach triggerga qaytadi.
- **Nomsiz qoldirmang.** `Field` ishlatmasangiz, `aria-label` yozing (masalan,
  `aria-label="Valyuta"`).
- **Belgilar.** Chevron, ✓ va `icon` ikonkalari `aria-hidden` — ekran o'quvchi faqat variant
  matnini o'qiydi.
