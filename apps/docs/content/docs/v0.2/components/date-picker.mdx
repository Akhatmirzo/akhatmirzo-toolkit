## Import

```tsx
import { Calendar, DatePicker, DateRangePicker } from '@akhatmirzo/ui';
```

Uchta komponent bitta kalendar ustida qurilgan:

| Komponent         | Vazifasi                                                            |
| ----------------- | ------------------------------------------------------------------- |
| `DatePicker`      | Bitta sana: Input ko'rinishidagi maydon + Popover'da kalendar       |
| `DateRangePicker` | Sanalar oralig'i: tugma-trigger + ikki oylik kalendar               |
| `Calendar`        | Popover'siz kalendar — sahifaga yoki o'z oynangizga joylashtiriladi |

## Qachon ishlatish

- **Aniq kun kerak bo'lsa** — yetkazish sanasi, uchrashuv, muddat. Faqat oy yoki yil kerak bo'lsa,
  oddiy [Select](./select.mdx) yetarli.
- **Tug'ilgan sana kabi uzoq sanalar uchun** ham `DatePicker` qulay: sanani klaviaturada yozib
  qo'yish mumkin, kalendar sarlavhasi bosilsa oy va yil tanlanadi.
- **Hisobot davri, ta'til, filtrlar** — `DateRangePicker`. Tayyor variantlar (`presets`) eng ko'p
  ishlatiladigan oraliqlarni bir bosishda beradi.
- **Cheklovlarni oldindan bering:** `minDate`, `maxDate`, `disabledDates`. Foydalanuvchi tanlab
  bo'lmaydigan kunni ko'radi, lekin bosa olmaydi — keyin xato chiqargandan ko'ra yaxshi.
- **Label uchun** maydonni [Field](./field.mdx) ichiga qo'ying — `id`, `aria-describedby` va
  xato holati avtomatik ulanadi.

## Qo'lda yozish

Maydonga to'g'ridan-to'g'ri yozish mumkin: `__.__.____` niqobi nuqtalarni o'zi qo'yadi, oxirgi
raqam kiritilganda sana tekshiriladi. Mavjud bo'lmagan sana (`31.02.2026`) — `invalid`, cheklovga
tushmaydigan sana — `unavailable` xatosi. Xato turini `onErrorChange` orqali olasiz.

<ComponentPreview name="date-picker/typing" />

<Callout title="Xato matni bitta joyda">
  Standart holatda `DatePicker` xatoni o'zi, maydon ostida ko'rsatadi. Agar `Field` ga `error`
  berilgan bo'lsa (yoki `invalid`), ichki xato qatori yashiriladi — ikki qator xato chiqmasligi
  uchun. Bu xatti-harakatni `showError` bilan majburan yoqish yoki o'chirish mumkin.
</Callout>

Niqob faqat raqamli shablonlarda ishlaydi (`dd.MM.yyyy`, `MM/dd/yyyy`). `format="d MMMM yyyy"`
kabi so'zli shablonda maydon oddiy matn sifatida tahlil qilinadi.

## Oy va yilni tanlash

Kalendar sarlavhasini ("Oktabr 2026") bosing — oylar, keyin yillar ko'rinishiga o'tiladi. Bu
tug'ilgan sana kabi uzoq sanalarga tez yetib borish uchun. `minDate` va `maxDate` dan tashqaridagi
oylar va yillar o'chirilgan bo'ladi.

<ComponentPreview name="date-picker/birthday" />

## Tayyor variantlar

`presets` — kalendar ostidagi tezkor tugmalar. `true` bersangiz: "Bugun", "Ertaga", "Bir haftadan
keyin". O'zingizniki uchun `DatePreset[]` bering:

```tsx
import { DatePicker, type DatePreset } from '@akhatmirzo/ui';

const presets: DatePreset[] = [
  {
    label: '3 kundan keyin',
    date: (today) => new Date(today.getFullYear(), today.getMonth(), today.getDate() + 3),
  },
  { label: 'Yangi yil', date: new Date(2027, 0, 1) },
];

<DatePicker presets={presets} />;
```

Agar variant sanasi cheklovga tushmasa (masalan, yakshanba yopiq), eng yaqin ruxsat etilgan
keyingi kun tanlanadi (31 kungacha qidiriladi).

## DateRangePicker

Oraliq ikkinchi kun bosilganda tasdiqlanadi. Birinchi kundan keyin kursor bilan yurganingizda
oraliq oldindan ko'rinadi. Kompyuterda ikki oy, telefonda bitta oy ko'rsatiladi. `presets` uchun
standart variantlar: "Bugun", "Oxirgi 7 kun", "Shu oy", "O'tgan oy".

<ComponentPreview name="date-picker/range" />

`onValueChange` faqat to'liq oraliq (`from` va `to` ikkalasi bor) bilan yoki tozalanganda `null`
bilan chaqiriladi — yarim tanlangan oraliq tashqariga chiqmaydi.

### O'z variantlaringiz va forma

`DateRangePreset` da `range` — obyekt yoki `today` ni oladigan funksiya. `name` bersangiz, formaga
ikkita yashirin maydon qo'shiladi: `${name}From` va `${name}To` (`yyyy-MM-dd`).

<ComponentPreview name="date-picker/range-presets" />

<Callout title="Qo'lda yozish faqat DatePicker'da">
  `DateRangePicker` ning trigger'i — tugma, unga matn yozilmaydi. Klaviatura bilan `Enter`, `Space`
  yoki `↓` bosing — kalendar ochiladi va fokus darhol kunga o'tadi.
</Callout>

### Tiplar

```ts
interface DateRangeValue {
  from: Date | null;
  to: Date | null; // null — oraliq hali tugallanmagan
}

interface DatePreset {
  label: string;
  date: Date | ((today: Date) => Date);
}

interface DateRangePreset {
  label: string;
  range: DateRangeValue | ((today: Date) => DateRangeValue);
}
```

`isDateSelectable(date, { minDate, maxDate, disabledDates })` ham eksport qilinadi — o'z
validatsiyangizda xuddi shu qoidani ishlatish uchun.

### Matnlar (`labels`)

Barcha matnlar o'zbekcha standart qiymatga ega. Boshqa tilga o'tkazish uchun kerakli kalitlarni
bering — qolganlari standartda qoladi:

```tsx
<DatePicker
  labels={{
    placeholder: 'dd.mm.yyyy',
    openCalendar: 'Open calendar',
    clear: 'Clear',
    invalidDate: 'Invalid date',
    months: ['January', 'February' /* ... */],
    weekdaysShort: ['Mo', 'Tu', 'We', 'Th', 'Fr', 'Sa', 'Su'],
  }}
/>
```

`CalendarLabels`: `previousMonth`, `nextMonth`, `previousYear`, `nextYear`, `previousYears`,
`nextYears`, `chooseMonth`, `chooseYear`, `monthsGrid`, `yearsGrid`, `navigation`, `today`,
`selected`, `months`, `monthsShort`, `weekdays`, `weekdaysShort` (hafta dushanbadan).
`DatePickerLabels` bularga qo'shimcha: `placeholder`, `openCalendar`, `calendar`, `clear`,
`presets`, `invalidDate`, `unavailableDate`, `today`, `tomorrow`, `inAWeek`.
`DateRangePickerLabels`: `placeholder`, `calendar`, `clear`, `presets`, `pickEnd`, `separator`,
`today`, `last7Days`, `thisMonth`, `lastMonth`.

## Klaviatura

| Tugma                 | Harakat                                                     |
| --------------------- | ----------------------------------------------------------- |
| `↓` (maydon/trigger)  | Kalendarni ochadi va fokusni kunga o'tkazadi                |
| `Enter` (maydonda)    | Yozilgan sanani tekshiradi va tasdiqlaydi                   |
| `← →`                 | ±1 kun                                                      |
| `↑ ↓`                 | ±1 hafta                                                    |
| `PageUp` / `PageDown` | ±1 oy (`Shift` bilan — ±1 yil)                              |
| `Home` / `End`        | Hafta boshi / oxiri                                         |
| `Enter` / `Space`     | Kunni tanlash                                               |
| `Esc`                 | Kalendarni yopadi; oy/yil ko'rinishida — kunlarga qaytaradi |

Oy va yil to'rida: strelkalar bilan yuriladi (`↑ ↓` — bir qator), `Home` / `End` — birinchi va
oxirgi element.

## Accessibility

- **Maydon** — oddiy `<input type="text">`: `aria-haspopup="dialog"`, `aria-expanded` va
  ochiq paytda `aria-controls` kalendar paneliga ishora qiladi. Raqamli shablonda mobil
  klaviatura raqamli bo'ladi (`inputMode="numeric"`).
- **Kalendar paneli** `aria-label="Kalendar"` bilan nomlangan; ochilganda fokus maydonda qoladi,
  `↓` yoki kalendar tugmasi bilan kunga o'tadi. Yopilganda fokus maydonga qaytadi.
- **Xato** `aria-invalid` bilan belgilanadi, xato matni `aria-describedby` orqali maydonga
  bog'langan va `aria-live="polite"` hududida e'lon qilinadi.
- **Kun tugmalari** ekran o'quvchi uchun to'liq nom oladi: bugungi kunga "Bugun", tanlanganiga
  "tanlangan" qo'shiladi. Tanlab bo'lmaydigan kunlar xira va ustidan chizilgan — bosilmaydi.
- **Oy va yil to'rlari** — `role="group"`, har bir katakda to'liq `aria-label`, joriy oy/yil
  `aria-current` bilan belgilangan.
- **DateRangePicker:** birinchi kun tanlangach "Tugash sanasini tanlang" matni `aria-live`
  hududida e'lon qilinadi; tayyor variant tugmalarida `aria-pressed` bor.
- **Ikonkalar** `aria-hidden`; "Kalendarni ochish" va "Tozalash" tugmalarida `aria-label` bor.
