## Import

```tsx
import { IconButton } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Joy tor bo'lsa va ikonka hammaga tanish bo'lsa** — yopish (✕), tahrirlash, o'chirish,
  toolbar tugmalari. Ma'nosi aniq bo'lmasa, matnli [`Button`](./button.mdx) ishlating.
- **`aria-label` — majburiy.** TypeScript usiz kompilyatsiya qilmaydi. Ekran o'quvchi ikonkani
  ko'rmaydi, faqat shu matnni o'qiydi — harakatni fe'l bilan yozing: "Yopish", "Tahrirlash".
- **Ko'rinadigan izoh kerak bo'lsa** — tugmani [`Tooltip`](./tooltip.mdx) ga o'rang.
- **Toolbar va jadval qatorlarida** `ghost` variant eng yengil ko'rinadi.

## Variantlar

`Button` dagi variantlar, `link` dan tashqari: `primary`, `soft` (standart), `outline`, `ghost`,
`danger`. Har birining ma'nosi [Button](./button.mdx) sahifasida.

## O'lchamlar

Kvadrat: 32, 40 va 48px — `Button`, `Input` balandliklari bilan bir xil. Ikonka o'lchami
avtomatik: 16 / 18 / 20px. `sm` ning ko'rinmas bosish maydoni 40px gacha kengaytirilgan.

## Holatlar

`loading` paytida ikonka o'rnida spinner aylanadi, tugma fokusda qoladi, bosish e'tiborsiz
qoldiriladi. Birinchi tugmani bosib ko'ring.

## Moslashtirish

Shakl va joylashuvni `className` bilan o'zgartirasiz — masalan, dumaloq "suzuvchi" tugma uchun
`rounded-full`. Pastdagi misolda `ghost` tugmalardan toolbar yig'ilgan.

## Havola sifatida (`asChild`)

`IconButton` ham `asChild` ni qabul qiladi: stil tugmaniki, element esa sizning `<a>` (yoki

## Accessibility

- **Nom majburiy.** `aria-label` TypeScript darajasida talab qilinadi — nomsiz tugma
  kompilyatsiyadan o'tmaydi.
- **Native `<button type="button">`** — `Enter` va `Space` bilan bosiladi, forma ichida
  tasodifan yubormaydi.
- **Ikonka ekran o'quvchidan yashiriladi** (`aria-hidden`), o'qiladigan yagona narsa —
  `aria-label`.
- **Yuklanish.** `aria-busy="true"` qo'yiladi va yashirin `aria-live` hudud `labels.loading`
  matnini e'lon qiladi.
- **Kichik o'lcham.** `size="sm"` ko'rinishda 32px, lekin bosish maydoni 40px.
