## Import

```tsx
import { SegmentedControl } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Ko'rinish rejimi** — "Katakli / Ro'yxat / Xarita". Tanlov darhol qo'llanadi.
- **Filtr yoki davr** — "Kun / Hafta / Oy", "Hammasi / To'langan / Qarz".
- **Variantlar 2–5 ta va qisqa** bo'lsin. Ko'p yoki uzun bo'lsa — [`Select`](./select.mdx) yoki
  [`RadioGroup`](./radio-group.mdx).
- **Yoqish/o'chirish uchun emas** — ikki holatli sozlamaga [`Switch`](./switch.mdx) mos.

## Tabs'dan farqi

Ikkalasi ham bir xil ko'rinishi mumkin, lekin vazifasi boshqa:

|             | `Tabs`                               | `SegmentedControl`                              |
| ----------- | ------------------------------------ | ----------------------------------------------- |
| Nima qiladi | Kontent **panellarini** almashtiradi | **Qiymat** tanlaydi (filtr, rejim, davr)        |
| Semantika   | `tablist` / `tab` / `tabpanel`       | `radiogroup` / `radio`                          |
| Natija      | Sahifaning boshqa bo'limi ko'rinadi  | Mavjud kontent qayta filtrlanadi yoki chiziladi |
| Forma       | Yo'q                                 | `name` bilan forma qiymati bo'ladi              |

Qoida: tanlovdan keyin **boshqa kontent** paydo bo'lsa — [`Tabs`](./tabs.mdx); **o'sha kontent**
boshqacha ko'rinsa yoki filtrlansa — `SegmentedControl`.

## O'lchamlar

`size` — `sm` (32px), `md` (40px, standart), `lg` (48px). Balandliklar [`Button`](./button.mdx) va
`Input` bilan bir xil, shuning uchun bir qatorda tekis turadi.

## Accessibility

- **Rollar.** Ildiz — `role="radiogroup"`, element — `role="radio"` (`aria-checked`). Asosida
  Radix RadioGroup: bitta tanlov, roving focus — guruh `Tab` uchun bitta to'xtash joyi.
- **Nom.** Guruhga `aria-label` bering ("Davr"). [`Field`](./field.mdx) ichida label guruh nomiga
  aylanadi, izoh `aria-describedby` ga ulanadi.
- **Faqat ikonkali element** — `aria-label` majburiy (TypeScript tekshiradi).
- **Indikator** bezak — `aria-hidden`. U tanlangan element o'lchamini o'qib, 200ms davomida
  siljiydi; o'lcham o'zgarsa (oyna kengligi, shrift yuklanishi) qayta hisoblanadi.
  `prefers-reduced-motion` da sakrab o'tadi.
