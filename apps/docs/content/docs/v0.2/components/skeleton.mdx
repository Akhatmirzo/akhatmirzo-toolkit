## Import

```tsx
import { Skeleton } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Kontentning shakli oldindan ma'lum bo'lsa** — kartalar, ro'yxatlar, profil, jadval.
  Yuklangandan keyin sahifa "sakramaydi".
- **Haqiqiy kontentga o'xshatib quring:** avatar o'rniga doira, sarlavha o'rniga qisqa qator,
  matn o'rniga `Skeleton.Text`.
- **Shakli noma'lum yoki qisqa kutishlar** (tugma bosilgandan keyin) uchun
  [`Spinner`](./spinner.mdx) yoki `Button` dagi `loading` mos.
- **Ota elementga `aria-busy`** qo'ying — skeletonlarning o'zi ekran o'quvchidan yashiringan.

## Shakllar

O'lcham `className` orqali beriladi (`h-4 w-32`, `size-10`). `variant="circle"` — avatar o'rni
uchun doira; standart `rect` burchaklari yumaloqlangan to'rtburchak.

## Accessibility

- **`aria-hidden="true"`** — skeletonlar ekran o'quvchiga ko'rinmaydi, bo'sh bloklar o'qilmaydi.
- **Yuklanish holatini ota elementda bildiring:** `aria-busy={loading}` (yuqoridagi misolda
  `Card` da). Kerak bo'lsa, yashirin "Yuklanmoqda" matnini qo'shing.
- **Kamaytirilgan harakat.** Tizimda "reduce motion" yoqilgan bo'lsa, shimmer o'rniga yumshoq
  pulsatsiya ishlatiladi.
