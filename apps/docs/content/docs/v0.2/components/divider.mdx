## Import

```tsx
import { Divider } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Mazmunan farq qiladigan bo'laklarni ajratish uchun** — chekdagi jami summa, menyu guruhlari,
  karta ichidagi bo'limlar.
- **Ko'pincha bo'shliq yetarli.** Har bir element orasiga chiziq qo'ymang — sahifa
  "panjara"ga aylanadi.
- **Muqobil yo'llar orasida** — `label="yoki"`: "Telefon orqali kirish" / "Google orqali kirish".
- **Faqat bezak bo'lsa** (masalan, navigatsiya bandlari orasida) — `decorative`.

## Matn bilan

`label` chiziq o'rtasiga matn qo'yadi. Matn satr bo'lsa, `aria-label` sifatida ham ishlatiladi.

## Vertikal

`orientation="vertical"` — qator ichida, balandligi ota elementga cho'ziladi. Ota elementga
balandlik bering (`h-5`) yoki `items-stretch`.

## Accessibility

- **`role="separator"`** va `aria-orientation` — ekran o'quvchi bo'limlar chegarasini aytadi.
- **`label`** satr bo'lsa, ajratuvchining `aria-label` iga aylanadi.
- **`decorative`** — `role="none"`: ma'nosiz chiziqlar o'qilmaydi. Navigatsiya bandlari, toolbar
  guruhlari orasidagi chiziqlar uchun.
