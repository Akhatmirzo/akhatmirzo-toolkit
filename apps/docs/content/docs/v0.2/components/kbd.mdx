
## Qachon ishlatish

- **Qisqa yo'llarni ko'rsatish uchun** — menyu bandlari, [`Tooltip`](./tooltip.mdx),
  [`CommandPalette`](./command-palette.mdx) va yordam matnlarida.
- **Kombinatsiyalar uchun `keys` massivini** ishlating — har bir tugma alohida chiziladi, `mod`
  esa operatsion tizimga qarab almashadi.
- **Bu faqat ko'rsatish.** `Kbd` tugma bosilishini tinglamaydi — buning uchun `useHotkeys` bor
  (pastda misol).
- **Har bir menyu bandiga qisqa yo'l yozmang** — faqat tez-tez ishlatiladigan harakatlarga.

## Tugmalar ro'yxati (`keys`)

`keys` dagi har bir element alohida chiziladi. `mod` (katta-kichik harf farqi yo'q) macOS va
iOS'da `⌘`, boshqa tizimlarda `Ctrl` ga aylanadi. Bitta tugma uchun oddiy `children` yetarli.

## Qisqa yo'lni ishlatish

`Kbd` va `@akhatmirzo/hooks` dagi `useHotkeys` bir xil `mod` qoidasiga amal qiladi: ko'rsatilgan
tugma va tinglanadigan tugma doim mos keladi.

```tsx title="search-hint.tsx"
import { useHotkeys } from '@akhatmirzo/hooks';
import { Kbd } from '@akhatmirzo/ui';
import { useState } from 'react';

export function SearchHint() {
  const [open, setOpen] = useState(false);
  useHotkeys('mod+k', () => setOpen(true));

  return (
    <p>
      Qidirish: <Kbd keys={['mod', 'K']} /> {open && '— ochildi'}
    </p>
  );
}
```

## Accessibility

- **Semantik `<kbd>` elementi** — bu klaviatura kiritishi ekani belgilanadi.
- **Belgilar** (`⌘`, `↵`, `↑`) ekran o'quvchida har doim ham tushunarli o'qilmaydi. Muhim
  ko'rsatmalarda belgi o'rniga so'z yozing: `<Kbd>Enter</Kbd>`.
