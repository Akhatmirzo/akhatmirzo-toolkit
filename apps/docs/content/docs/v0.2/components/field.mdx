## Import

```tsx
import { Field } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Har bir forma maydoni uchun** — `Input`, `Textarea`, `Select`, `Checkbox`, `RadioGroup`,
  `Switch` va boshqalar. `id`, `htmlFor`, `aria-describedby`, `aria-invalid`, `aria-required`
  ni qo'lda yozish shart emas.
- **Xatoni `error` ga bering**, alohida `<p>` ga emas — shunda boshqaruv elementi ham qizil
  bo'ladi, ekran o'quvchi ham xatoni o'qiydi.
- **`description` — qisqa yo'l-yo'riq** uchun: format, cheklov, nima uchun kerakligi. Uzun
  matnni sahifaga chiqaring.
- **Bitta `Field` — bitta boshqaruv elementi.** Ikki maydonni bitta label ostiga qo'ymang.

## Validatsiya

`error` bo'sh bo'lmasa, maydon xato holatiga o'tadi: boshqaruv elementi `aria-invalid` oladi,
chegarasi qizarib, ostida ikonka bilan xato matni chiqadi. Xatolar `aria-live` hududida —
paydo bo'lganda ekran o'quvchi e'lon qiladi. Formani bo'sh holda yuborib ko'ring.

## O'z boshqaruv elementingiz (`useFieldControl`)

Kutubxonadagi barcha forma komponentlari `useFieldControl` hook'i orqali `Field` ga ulanadi. Siz
ham o'z elementingizni (native `<select>`, uchinchi tomon kutubxonasi) shu hook bilan ulaysiz:
`controlProps` ni elementga yoyasiz — qolgani avtomatik.

<ComponentPreview name="archive/v0.2/field/custom-control" />

`useFieldControl` `Field` tashqarisida ham ishlaydi — u holda o'zining `id` sini yaratadi.

### useFieldControl

```ts
function useFieldControl(options?: FieldControlOptions): FieldControlResult;
```

`options` — elementning o'z qiymatlari; ular `Field` dan kelganlari bilan birlashtiriladi
(`invalid`, `required`, `disabled` — "yoki" mantig'ida).

| `data-invalid`     | `error` bo'lganda mavjud    |
| `data-disabled`    | `disabled` bo'lganda mavjud |

## Accessibility

- **Label bog'lanadi.** `<label htmlFor>` boshqaruv elementining `id` siga ulanadi; elementga
  o'z `id` ingizni bersangiz, label shunga moslashadi.
- **Izoh va xato** `aria-describedby` orqali o'qiladi — fokus maydonga kelganda ekran o'quvchi
  label'dan keyin ularni ham aytadi.
- **Xato e'loni.** Xato matni doim DOM'da turadigan `aria-live="polite"` hudud ichida — birinchi
  paydo bo'lgan xato ham e'lon qilinadi.
- **Majburiy maydon.** `*` belgisi `aria-hidden`, o'rniga elementga `aria-required` qo'yiladi.
- **`RadioGroup` kabi `<div>` elementlar** label bilan `htmlFor` orqali bog'lanmaydi — ular
  `labelId` orqali `aria-labelledby` oladi (avtomatik).
