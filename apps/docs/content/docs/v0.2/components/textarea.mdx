## Import

```tsx
import { Textarea } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Erkin, ko'p qatorli matn uchun** — izoh, manzil, sharh, xabar. Bir qatorli qiymatga
  [`Input`](./input.mdx).
- **Doim [`Field`](./field.mdx) ichida** — label, izoh va xato o'zi ulanadi.
- **Chat va izoh maydonlarida `autoResize`** ishlating: maydon matn bilan birga o'sadi,
  `maxRows` dan keyin ichki scroll paydo bo'ladi.
- **Cheklov bo'lsa, `maxLength` ni `showCount` bilan** bering — foydalanuvchi qancha joy qolganini
  ko'rib turadi.

## Avtomatik balandlik

`autoResize` — balandlik `minRows` dan `maxRows` gacha matnga moslashadi. `maxRows` berilmasa,
cheklovsiz o'sadi. Bu rejimda qo'lda cho'zish (resize) o'chiriladi.

## Belgilar soni

`showCount` maydon ostida belgilar sonini ko'rsatadi; `maxLength` bilan "64 / 120" ko'rinishida.

`onChange` ...) qabul qiladi; `ref` ichki `<textarea>` ga tushadi. `rows` o'rniga `minRows`
ishlatiladi. `className` — tashqi konteynerga, ichki elementga — `textareaClassName`.

### Data atributlari

Atributlar tashqi konteynerda (`data-slot="textarea"`): `data-size`, `data-invalid`,
`data-disabled`, `data-readonly`. Hisoblagich elementi — `data-slot="textarea-count"`.

## Accessibility

- **Native `<textarea>`** — `Tab` bilan fokuslanadi, `Enter` yangi qator qo'shadi.
- **Field bilan** `id`, `aria-describedby`, `aria-invalid` va `aria-required` avtomatik ulanadi.
- **Hisoblagich** `aria-describedby` ga qo'shiladi — ekran o'quvchi maydonga kelganda limitni
  ham aytadi.
