## What's inside

- Search (customer or number) plus status and region `Select`s; changing a filter goes back to page 1.
- Each row has `DropdownMenu` actions: details, receipt, cancel.
- No results — an `EmptyState` with a "Clear filters" action.
- `Pagination` and `PaginationInfo` below the table, stacked in narrow containers.
