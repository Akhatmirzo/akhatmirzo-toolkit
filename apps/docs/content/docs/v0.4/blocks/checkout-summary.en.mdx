## What's inside

- Change quantities or remove items; an empty cart shows an `EmptyState`.
- Promo codes: `TOSHKENT10` or `YANGI15`; a wrong code shows an error under the field.
- Delivery is free from 1 000 000 so'm — the total updates instantly.
- The `Stepper` is compact in narrow containers and full in wide ones.

## Installation

The CLI copies the block file into your project (`components/blocks/checkout-summary.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add checkout-summary
```

Manually: install the packages and copy the file from the "Code" tab into your project.
