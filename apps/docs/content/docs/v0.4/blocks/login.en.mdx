## What's inside

- Phone or email, switched with a `SegmentedControl`; `PhoneInput` handles the +998 format.
- Validation with `parsePhone` and `isValidEmail`; errors show under each field.
- A "server" error (`Alert`) — try a password shorter than 8 characters.
- Wide containers get a brand panel on the left, narrow ones show the form only.

The CLI copies the block file into your project (`components/blocks/login.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add login
```

Manually: install the packages and copy the file from the "Code" tab into your project.
