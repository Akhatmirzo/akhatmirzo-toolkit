## Tarkibi

- Sidebar guruhlari, nishonlar (`badge`) va pastda profil menyusi.
- `Ctrl/⌘ + B` yoki tugma bilan sidebar yig'iladi; holat `localStorage` da saqlanadi.
- 1024px dan tor oynada sidebar chapdan chiquvchi `Drawer` ga aylanadi.
- Sahifa kontenti `@container` — o'z kengligiga qarab moslashadi.
