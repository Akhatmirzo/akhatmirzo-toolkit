## Tarkibi

- Qidiruv (mijoz yoki raqam), holat va hudud `Select` lari; filtr o'zgarsa birinchi sahifaga qaytadi.
- Har qatorda `DropdownMenu` amallari: batafsil, chek, bekor qilish.
- Natija bo'lmasa — `EmptyState` va "Filtrlarni tozalash".
- `Pagination` va `PaginationInfo` jadval ostida, torda ustma-ust.
