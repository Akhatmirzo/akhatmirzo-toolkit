## What's inside

- First and last name sit side by side in wide containers and stack in narrow ones.
- Password strength — `passwordStrength` drives a live `Progress` bar and checklist.
- After the first submit, errors update as you type.
- Terms consent — a `Checkbox` with links in its label.
