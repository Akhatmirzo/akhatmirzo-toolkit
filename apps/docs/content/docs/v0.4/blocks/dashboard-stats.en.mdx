## What's inside

- Period (7 days / 30 days / year) switches every metric and the chart together.
- Change is a `Badge`: green for growth, red for decline; the `Sparkline` is decorative (`aria-hidden`).
- Cards flow into 1, 2 or 4 columns depending on container width.
- Charts rely on `recharts` via the separate `@akhatmirzo/ui/charts` entry point.

## Installation

The CLI copies the block file into your project (`components/blocks/dashboard-stats.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add dashboard-stats
```

Manually: install the packages and copy the file from the "Code" tab into your project.
