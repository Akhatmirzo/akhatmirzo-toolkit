## What's inside

- Sidebar groups, badges and a profile menu at the bottom.
- `Ctrl/⌘ + B` or the toggle collapses the sidebar; the state persists in `localStorage`.
- Below 1024px the sidebar becomes a `Drawer` from the left.
- Page content is an `@container` and adapts to its own width.

## Installation

The CLI copies the block file into your project (`components/blocks/app-shell-layout.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add app-shell-layout
```

Manually: install the packages and copy the file from the "Code" tab into your project.
