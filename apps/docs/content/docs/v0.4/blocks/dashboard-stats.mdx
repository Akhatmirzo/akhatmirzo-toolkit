## Tarkibi

- Davr (7 kun / 30 kun / yil) — barcha ko'rsatkichlar va grafik birga almashadi.
- O'zgarish foizi `Badge` bilan: o'sish yashil, pasayish qizil; `Sparkline` — bezak (`aria-hidden`).
- Kartochkalar konteyner kengligiga qarab 1, 2 yoki 4 ustunda.
- Grafiklar `recharts` ga tayanadi — `@akhatmirzo/ui/charts` alohida kirish nuqtasidan.

## O'rnatish

CLI blok faylini loyihangizga (`components/blocks/dashboard-stats.tsx`) ko'chiradi va kerakli paketlarni
o'rnatishni taklif qiladi:

```bash
npx @akhatmirzo/cli add dashboard-stats
```

Qo'lda: paketlarni o'rnating va "Kod" tabidagi faylni loyihangizga nusxalang.
