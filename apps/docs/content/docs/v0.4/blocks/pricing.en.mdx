## What's inside

- Monthly/yearly — a `SegmentedControl`; yearly applies a 20% discount and shows the savings.
- Prices use `formatMoney`: "279 000 so'm / oy".
- The popular plan is highlighted; cards stack in narrow containers.

## Installation

The CLI copies the block file into your project (`components/blocks/pricing.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add pricing
```

Manually: install the packages and copy the file from the "Code" tab into your project.
