## What's inside

- `Form` + `FormField` on `react-hook-form` with `zodResolver`; messages are in Uzbek (`zUz`).
- The avatar uses the `FormField render` escape hatch for a custom control (pick, preview, remove).
- `zUz.phone()` normalizes the value to `998901234567`, `zUz.region()` returns a region id.
- Server errors go to `FormRootError` (try the email `band@misol.uz`).

## Installation

The CLI copies the block file into your project (`components/blocks/settings-profile.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add settings-profile
```

Manually: install the packages and copy the file from the "Code" tab into your project.
