## What's inside

- The code is checked automatically once complete (`onComplete`); the test code is `246810`.
- A wrong code marks the field `invalid` and shows the remaining attempts.
- The resend button stays disabled until `useCountdown(59)` finishes.
- A success state after verification.

## Installation

The CLI copies the block file into your project (`components/blocks/otp-verify.tsx`) and offers to
install the packages it needs:

```bash
npx @akhatmirzo/cli add otp-verify
```

Manually: install the packages and copy the file from the "Code" tab into your project.
