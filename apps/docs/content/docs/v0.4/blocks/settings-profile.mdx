## Tarkibi

- `Form` + `FormField` — `react-hook-form` va `zodResolver`; xato matnlari o'zbekcha (`zUz`).
- Avatar — `FormField render` zaxira yo'li bilan maxsus boshqaruv (fayl tanlash, ko'rish, o'chirish).
- `zUz.phone()` qiymatni `998901234567` ko'rinishiga keltiradi, `zUz.region()` — hudud id'si.
- Server xatosi — `FormRootError` (`band@misol.uz` emailida sinab ko'ring).
