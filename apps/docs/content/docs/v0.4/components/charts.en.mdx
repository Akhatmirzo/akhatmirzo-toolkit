## Installation

Charts live in a separate entry point — `@akhatmirzo/ui/charts`. They are built on
[Recharts](https://recharts.github.io), which is an **optional** peer dependency: if you don't use
charts, you don't need to install it, and the main `@akhatmirzo/ui` import never pulls it in.

<Install pkg="recharts" />

## Import

```tsx
import { AreaChart, BarChart, LineChart, DonutChart, Sparkline } from '@akhatmirzo/ui/charts';
```

## When to use

- **Change over time** — `AreaChart` or `LineChart` (monthly revenue, daily visits).
- **Comparing categories** — `BarChart` (regions, products). For long names use
  `orientation="horizontal"`.
- **Parts of a whole** — `DonutChart`, with no more than 5–6 slices; group the rest into "Other".
- **A small trend** — `Sparkline` in KPI cards and table cells.
- **When exact values matter** — show a table instead of, or next to, the chart (see
  [Accessibility](#accessibility)).

## Ready-made charts

They all share the same props: `data` is a list of objects, `index` is the category field (x axis)
and `series` lists the numeric fields to draw. Colors come only from tokens, so charts adapt to dark
mode on their own.

### AreaChart

The example above. `stacked` stacks the series on top of each other; `curve` is `monotone`
(default), `linear` or `step`.

### BarChart

`stacked` puts the series into one bar, showing the total and its breakdown together.

<ComponentPreview name="charts/bar" align="start" />

`orientation="horizontal"` draws horizontal bars — handy for long names and rankings. The prop is
named after what you see (`vertical` — upright columns) and deliberately differs from Recharts'
`layout`, where `layout="vertical"` means the opposite (horizontal bars).

### LineChart

For comparing several metrics. This one uses `curve="linear"`.

### DonutChart

`index` is the slice name and `value` is the value field. The center shows `centerLabel` and the
total (formatted with `valueFormat`); override it with `centerValue` or hide it with `null`.

### Sparkline

A tiny line with no axes, grid or tooltip. If the value is already shown as text next to it, mark
it as decorative with `aria-hidden`; otherwise give it an `aria-label`.

## Formatting

`valueFormat` controls the tooltip and the value axis (default `formatNumber`: `1 250 000`);
`indexFormat` controls the category axis and the tooltip title. Use `formatMoney` for money; if
long values crowd the axis, pass a short form (`42,5 mln so'm`).

```tsx
import { formatMoney } from '@akhatmirzo/core';

<BarChart valueFormat={(v) => formatMoney(v)} indexFormat={(d) => d.slice(0, 3)} … />
```

## States

`loading` shows a Skeleton in place of the chart (`aria-busy`); empty data shows an `EmptyState`
("Ma'lumot yo'q"). Pass your own empty state with `emptyState` and change the texts with `labels`.

## Primitives: build your own chart

When a ready-made chart isn't enough (dual axes, mixed series, custom shapes), compose Recharts
directly — the primitives give it the library look:

- `ChartContainer` — a responsive wrapper: `role="figure"` + `aria-label` (required), `description`,
  and `config` → CSS variables (`revenue` → `var(--chart-revenue)`). Set the height with `height` or
  `className="h-72"` (default 280px).
- `ChartTooltip` — `<Tooltip content={<ChartTooltip format={formatMoney} />} />`; takes series
  names from `label` in `config`.
- `ChartLegend` — `<Legend content={<ChartLegend />} />`, or outside a chart with `payload`.
- `chartColors` (5 series colors), `axisProps`, `gridProps`, `cursorProps`, `resolveChartColor`.

`ChartColor` is a token name (`primary`, `success`, `warning`, `danger`, `info`, `neutral`, `sky`,
`emerald`, `amber`, `rose`) or any CSS value (`var(--ak-indigo-400)`). Hex values don't adapt to
dark mode — prefer tokens.

### Data attributes

On the root of ready-made charts: `data-state` (`ready` · `loading` · `empty`), `data-loading`.

## Accessibility

- **A name is required** — every chart gets `role="figure"` and an `aria-label` (or `title`) — not
  `img`, because the keyboard layer inside is interactive and `img` hides its children; `Sparkline`
  uses `img`. Say what is shown and for which period: "Monthly revenue, January–June".
- **Summary** — put the key takeaway in `description` ("Revenue reached 63M so'm in June"); it is
  read through `aria-describedby`.
- **Keyboard** — Recharts' `accessibilityLayer` is on: Tab into the chart and move between points
  with `←` `→`; the tooltip follows. `Sparkline` has no tooltip, so it doesn't take focus.
- **Offer a table view too** — charts are bad at conveying exact values. In important reports add
  a "Chart / Table" switch or a table below the chart:

<ComponentPreview name="charts/table-view" align="start" />

- **Color is not the only signal** — the legend and tooltip name each series in text.
- **Motion** — with `prefers-reduced-motion` enabled, Recharts turns off its entry animation.
