## Import

```tsx
import { Progress, ProgressCircle } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Davomiyligi ma'lum jarayon uchun** — fayl yuklash, eksport, profilni to'ldirish darajasi.
- **Qancha vaqt ketishi noma'lum bo'lsa** — `value={null}` (noaniq holat) bering.
- **Qisqa kutish uchun** (1 soniyadan kam) — progress shart emas; tugma ichida
  [`Spinner`](./spinner.mdx) yetarli.
- **Doira** — kartochka, avatar yonida yoki joy tor bo'lganda; **chiziq** — ro'yxat va formalarda.
- **Qiymatni matn bilan ham ko'rsating** (`showValue`) — foydalanuvchi aniq raqamni ko'rsin.

## Noaniq holat

`value` berilmasa yoki `null` bo'lsa — chiziqda bo'lak chapdan o'ngga yuradi, doira aylanadi.
Harakatni kamaytirish yoqilgan bo'lsa (`prefers-reduced-motion`), faqat yumshoq miltillash qoladi.

## Ranglar va o'lchamlar

`color`: `primary` (standart), `success`, `warning`, `danger`. `size`: `sm` — 4px, `md` — 8px,
`lg` — 12px chiziq.

<ComponentPreview name="progress/colors-sizes" />

## ProgressCircle

Doira o'lchamlari: `sm` — 24px, `md` — 40px, `lg` — 64px. `showValue` qiymatni markazda
ko'rsatadi (`sm` da joy yetmaydi, shuning uchun ko'rsatilmaydi). Doirada `label` ko'rinmaydi —
ekran o'quvchi uchun nom bo'ladi.

### Data atributlari

Ildiz elementda: `data-state` (`indeterminate` · `loading` · `complete`), `data-color`,
`data-size`.

## Accessibility

- **`role="progressbar"`** — `aria-valuemin`, `aria-valuemax`, `aria-valuenow` va
  `aria-valuetext` (`formatValue` natijasi) avtomatik qo'yiladi.
- **Noaniq holatda** `aria-valuenow` va `aria-valuetext` qo'yilmaydi — ekran o'quvchi buni
  "band" deb tushunadi.
- **Nom majburiy:** `label` bering yoki `aria-label` / `aria-labelledby` ni o'zingiz qo'ying.
  Chiziqda `label` `aria-labelledby` orqali ulanadi; doirada matnli `label` `aria-label` bo'ladi.
- **Ko'rinadigan qiymat** `aria-hidden` — u allaqachon `aria-valuetext` da o'qiladi.
- **Harakatni kamaytirish** yoqilganda siljish va aylanish o'chadi, faqat miltillash qoladi.
