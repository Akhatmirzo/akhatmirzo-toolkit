## Import

```tsx
import { ContextMenu } from '@akhatmirzo/ui';
```

## When to use

- **Quick actions on a file, card or table row** — desktop users expect the right click.
- **Only as an extra path.** Not everyone discovers right-click menus, and on phones they open with
  a long press. Make important actions available elsewhere too — a button or a
  [`DropdownMenu`](./dropdown-menu.mdx).
- **Need a menu that opens on a button click?** Use [`DropdownMenu`](./dropdown-menu.mdx). Both
  share the same parts, so you can write the actions once and use them in both places.

## Anatomy

Parts, props and styles match [`DropdownMenu`](./dropdown-menu.mdx) (the styles come from a shared
module). The difference: `Trigger` is not a button but the **area** you right-click, and the panel
opens at the pointer.

| Part                                            | What it does                                            |
| ----------------------------------------------- | ------------------------------------------------------- |
| `ContextMenu`                                   | State: `onOpenChange`, `modal`, `dir`                   |
| `ContextMenu.Trigger`                           | The area (an unstyled `<span>`; usually with `asChild`) |
| `ContextMenu.Content`                           | The panel: portal, opens at the pointer, looping nav    |
| `ContextMenu.Item`                              | An action: `icon`, `shortcut`, `variant`, `onSelect`    |
| `ContextMenu.CheckboxItem`                      | A toggleable item (✓)                                   |
| `ContextMenu.RadioGroup` / `RadioItem`          | One choice out of several (●)                           |
| `ContextMenu.Label` / `Group` / `Separator`     | Heading, group and divider                              |
| `ContextMenu.Sub` / `SubTrigger` / `SubContent` | A submenu                                               |

```tsx
<ContextMenu>
  <ContextMenu.Trigger asChild>
    <Card>…file…</Card>
  </ContextMenu.Trigger>
  <ContextMenu.Content>
    <ContextMenu.Item icon={<Pencil />} shortcut={['mod', 'E']}>
      Edit
    </ContextMenu.Item>
    <ContextMenu.Separator />
    <ContextMenu.Item variant="danger">Delete</ContextMenu.Item>
  </ContextMenu.Content>
</ContextMenu>
```

## Checkable items

`CheckboxItem` (`checked` / `onCheckedChange`) and `RadioGroup` (`value` / `onValueChange`, or
`defaultValue`) work well for view settings.

## Table row: two ways in

Right-click a row for the ContextMenu, or use the "⋯" button for a DropdownMenu with the same
actions. Since the part names match, the actions live in a single component. The submenu opens with
`→` or on hover.

### Data attributes

| Attribute          | Where              | Value                         |
| ------------------ | ------------------ | ----------------------------- |
| `data-state`       | trigger, panel     | `open` · `closed`             |
| `data-variant`     | item               | `default` · `danger`          |
| `data-highlighted` | item               | under the keyboard or pointer |
| `data-disabled`    | item, trigger      | present when disabled         |
| `data-state`       | Checkbox/RadioItem | `checked` · `unchecked`       |

## Keyboard

| Key               | Action                                       |
| ----------------- | -------------------------------------------- |
| `Shift` + `F10`   | Opens the menu on the focused area (browser) |
| `↓` / `↑`         | Move between items (wraps around)            |
| `Home` / `End`    | First / last item                            |
| Letter            | Jump to the item starting with that letter   |
| `→` / `←`         | Open / close a submenu                       |
| `Enter` / `Space` | Select and close                             |
| `Esc`             | Close                                        |

## Accessibility

- **Roles.** The panel is `role="menu"`, items are `menuitem`, `menuitemcheckbox`,
  `menuitemradio`. Built on Radix ContextMenu.
- **Hard to discover.** A right-click menu is invisible to screen reader and keyboard users — always
  provide important actions another way too.
- **Shortcuts.** With `shortcut`, the item gets `aria-keyshortcuts`; the visible `Kbd` is hidden
  from screen readers. The label does not listen for the key — wire it up with
  [`useHotkeys`](../hooks.mdx).
- **Icons** are `aria-hidden`.
