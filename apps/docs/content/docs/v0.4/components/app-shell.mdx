## Import

```tsx
import { AppShell, Sidebar, useAppShell } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Admin panel, CRM, dashboard** — chapda doimiy menyu, o'ngda sahifa kontenti.
- **Ko'p bo'limli ilova**, foydalanuvchi bo'limlar orasida tez-tez o'tadi.
- **Marketing sahifa, blog** uchun emas — u yerda yuqori navigatsiya qulayroq.
- Qolip butun ekranni egallaydi; uni ilova `layout` ida **bir marta** qo'ying.

## Tuzilishi

| Qism                     | Vazifasi                                                                 |
| ------------------------ | ------------------------------------------------------------------------ |
| `AppShell`               | Holat (yig'ilgan/to'liq), saqlash, `mod+B` yorlig'i, skip link           |
| `Sidebar`                | Desktop'da chapdagi panel (256px ↔ 64px), `< 1024px` da chapdan `Drawer` |
| `Sidebar.Header`         | Logotip, ilova nomi                                                      |
| `Sidebar.Content`        | `<nav aria-label="Asosiy menyu">`, aylantiriladi                         |
| `Sidebar.Group`          | Sarlavha + elementlar ro'yxati; `collapsible` bo'lishi mumkin            |
| `Sidebar.Item`           | Havola (`href`), tugma (`onClick`) yoki `renderLink` orqali Next `Link`  |
| `Sidebar.Footer`         | Pastki qism: foydalanuvchi menyusi                                       |
| `AppShell.Main`          | `<main>` — skip link shu yerga olib keladi                               |
| `AppShell.Header`        | Yopishqoq (`sticky top-0`), 56px, pastki chegara                         |
| `AppShell.SidebarToggle` | Sidebar tugmasi: desktop'da yig'adi, telefonda Drawer'ni ochadi          |

## Yig'ilgan holat

Desktop'da (`≥ 1024px`) sidebar 64px'lik ikonkalar qatoriga yig'iladi: element nomlari
yashiriladi, har birida `Tooltip` va `aria-label` paydo bo'ladi, hisoblagich nuqtaga aylanadi.
Yig'ish — `AppShell.SidebarToggle` yoki `Ctrl/⌘ + B`. Animatsiya `grid-template-columns` orqali,
`prefers-reduced-motion` da sakrab o'tadi.

`collapsible` guruh sarlavhasi bosilganda yig'iladi (Accordion uslubida); yig'ilgan panelda
guruhlar doim ochiq, sarlavha o'rnida ajratuvchi chiziq.

## Holatni saqlash

`sidebarStorageKey` berilsa, holat `localStorage` ga yoziladi va keyingi tashrifda tiklanadi.
SSR-xavfsiz: serverda va birinchi renderda `defaultSidebarOpen` chiziladi, saqlangan qiymat
mount'dan keyin o'qiladi (hydration xatosi bo'lmaydi). Storage taqiqlangan bo'lsa ham holat
ishlayveradi.

## Telefon va planshet

`< 1024px` da sidebar o'rniga chapdan chiqadigan [`Drawer`](./drawer.mdx) ishlatiladi:
`AppShell.SidebarToggle` uni ochadi, `Sidebar.Item` bosilganda (sahifa o'tishi) o'zi yopiladi.
Desktop/mobil almashuvi CSS breakpoint orqali — server va brauzer bir xil HTML chizadi.

## Next.js Link bilan

`renderLink` — o'z havola komponentingizni ishlatish uchun. Unga `href`, `className`,
`aria-current`, `onClick` va ichki kontent beriladi — hammasini yoying.

```tsx
'use client';
import Link from 'next/link';
import { usePathname } from 'next/navigation';

function NavItem({ href, icon, children }) {
  const pathname = usePathname();
  return (
    <Sidebar.Item
      href={href}
      icon={icon}
      active={pathname.startsWith(href)}
      renderLink={(props) => <Link {...props} />}
    >
      {children}
    </Sidebar.Item>
  );
}
```

## Klaviatura

| Tugma            | Harakat                                             |
| ---------------- | --------------------------------------------------- |
| `Tab` (birinchi) | "Asosiy kontentga o'tish" havolasi chiqadi          |
| `Ctrl/⌘ + B`     | Desktop'da yig'ish/yoyish, telefonda menyuni ochish |
| `Esc`            | Mobil menyuni yopadi                                |

## Accessibility

- **Skip link.** `AppShell` sahifa boshiga "Asosiy kontentga o'tish" havolasini qo'yadi — u
  faqat klaviatura fokusida ko'rinadi va `AppShell.Main` ga olib o'tadi.
- **Navigatsiya.** Menyu `<nav aria-label="Asosiy menyu">` ichida, faol element
  `aria-current="page"` oladi; guruhlar `role="group"` va sarlavha bilan bog'langan.
- **Yig'ilgan holat.** Matn yashirinsa ham har element nomini saqlaydi: `aria-label` va
  `Tooltip`. Hisoblagich ekran o'quvchi uchun matn sifatida qoladi.
- **Toggle.** `AppShell.SidebarToggle` `aria-expanded` va `aria-controls` oladi (desktop'da —
  panel, telefonda — Drawer).
- **Mobil menyu** — `Drawer`: fokus ichida qoladi, `Esc` yopadi, fokus tugmaga qaytadi.
