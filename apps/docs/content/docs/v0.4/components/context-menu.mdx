## Import

```tsx
import { ContextMenu } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Fayl, karta, jadval qatori** ustidagi tezkor amallar — kompyuterda ishlaydigan foydalanuvchilar
  o'ng tugmani kutadi.
- **Faqat qo'shimcha yo'l sifatida.** O'ng tugma menyusini hamma ham topmaydi, telefonda esa u
  uzoq bosish bilan ochiladi. Muhim amallar boshqa joyda ham — tugma yoki
  [`DropdownMenu`](./dropdown-menu.mdx) orqali — mavjud bo'lsin.
- **Tugma bosilganda ochiladigan menyu** kerak bo'lsa — [`DropdownMenu`](./dropdown-menu.mdx).
  Ikkalasining qismlari bir xil, amallarni bir marta yozib, ikkala joyda ishlatish mumkin.

## Tuzilishi

Qismlar, prop'lar va stillar [`DropdownMenu`](./dropdown-menu.mdx) bilan bir xil (stillar umumiy
moduldan olinadi). Farqi — `Trigger` tugma emas, o'ng tugma bosiladigan **hudud**, panel esa
kursor turgan joyda ochiladi.

| Qism                                            | Vazifasi                                                   |
| ----------------------------------------------- | ---------------------------------------------------------- |
| `ContextMenu`                                   | Holat: `onOpenChange`, `modal`, `dir`                      |
| `ContextMenu.Trigger`                           | Hudud (stilsiz `<span>`; odatda `asChild` bilan)           |
| `ContextMenu.Content`                           | Panel: portal, kursor yonida ochiladi, aylanma navigatsiya |
| `ContextMenu.Item`                              | Amal: `icon`, `shortcut`, `variant`, `onSelect`            |
| `ContextMenu.CheckboxItem`                      | Yoqib-o'chiriladigan element (✓)                           |
| `ContextMenu.RadioGroup` / `RadioItem`          | Bir nechtadan bittasini tanlash (●)                        |
| `ContextMenu.Label` / `Group` / `Separator`     | Sarlavha, guruh va ajratuvchi chiziq                       |
| `ContextMenu.Sub` / `SubTrigger` / `SubContent` | Ichki menyu                                                |

```tsx
<ContextMenu>
  <ContextMenu.Trigger asChild>
    <Card>…fayl…</Card>
  </ContextMenu.Trigger>
  <ContextMenu.Content>
    <ContextMenu.Item icon={<Pencil />} shortcut={['mod', 'E']}>
      Tahrirlash
    </ContextMenu.Item>
    <ContextMenu.Separator />
    <ContextMenu.Item variant="danger">O'chirish</ContextMenu.Item>
  </ContextMenu.Content>
</ContextMenu>
```

## Belgilanadigan elementlar

`CheckboxItem` (`checked` / `onCheckedChange`) va `RadioGroup` (`value` / `onValueChange` yoki
`defaultValue`) — ko'rinish sozlamalari uchun qulay.

## Jadval qatori: ikki yo'l bilan

Qator ustida o'ng tugma — ContextMenu, "⋯" tugmasi — xuddi shu amallar bilan DropdownMenu.
Qismlar nomi bir xil bo'lgani uchun amallar bitta komponentda yoziladi. Ichki menyu `→` yoki
kursor bilan ochiladi.

### Data atributlari

| Atribut            | Qayerda            | Qiymat                            |
| ------------------ | ------------------ | --------------------------------- |
| `data-state`       | trigger, panel     | `open` · `closed`                 |
| `data-variant`     | element            | `default` · `danger`              |
| `data-highlighted` | element            | klaviatura yoki sichqoncha ustida |
| `data-disabled`    | element, trigger   | o'chirilganda mavjud              |
| `data-state`       | Checkbox/RadioItem | `checked` · `unchecked`           |

## Klaviatura

| Tugma             | Harakat                                        |
| ----------------- | ---------------------------------------------- |
| `Shift` + `F10`   | Fokusdagi hududda menyuni ochadi (brauzer)     |
| `↓` / `↑`         | Elementlar bo'ylab yurish (aylanma)            |
| `Home` / `End`    | Birinchi / oxirgi element                      |
| Harf              | Shu harf bilan boshlanadigan elementga sakrash |
| `→` / `←`         | Ichki menyuni ochish / yopish                  |
| `Enter` / `Space` | Tanlash va yopish                              |
| `Esc`             | Yopish                                         |

## Accessibility

- **Rollar.** Panel — `role="menu"`, elementlar — `menuitem`, `menuitemcheckbox`,
  `menuitemradio`. Asosida Radix ContextMenu.
- **Topilishi qiyin.** O'ng tugma menyusi ekran o'quvchi va klaviatura foydalanuvchilari uchun
  ko'rinmaydi — muhim amallarni albatta boshqa yo'l bilan ham bering.
- **Qisqa yo'llar.** `shortcut` berilsa, `aria-keyshortcuts` qo'yiladi; ko'rinadigan `Kbd` ekran
  o'quvchidan yashirin. Yorliq tugmani o'zi tinglamaydi — [`useHotkeys`](../hooks.mdx) bilan
  ulang.
- **Ikonkalar** `aria-hidden`.
