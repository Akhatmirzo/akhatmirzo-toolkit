## Import

```tsx
import { ColorPicker } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Foydalanuvchi o'z rangini tanlaydi** — brend rangi, teg yoki kategoriya rangi, mavzu
  sozlamalari.
- **Ranglar soni cheklangan bo'lsa** — `swatches` bilan tayyor palitrani bering; erkin tanlash
  baribir mavjud qoladi.
- **Faqat bir nechta rangdan tanlash kerak bo'lsa** (5–6 ta) — `RadioGroup` yoki
  [`SegmentedControl`](./segmented-control.mdx) bilan rangli namunalar soddaroq.

## Tuzilishi

Trigger — [`Input`](./input.mdx) ko'rinishidagi tugma: chapda rang namunasi, yonida hex matn.
Bosilganda [`Popover`](./popover.mdx) ochiladi:

1. **To'yinganlik maydoni** (2D) — gorizontal o'q to'yinganlik, vertikal — yorqinlik.
2. **Hue slayderi** — rang tusi (0–360°), [`Slider`](./slider.mdx) komponenti.
3. **Shaffoflik slayderi** — faqat `alpha` bilan.
4. **Pipetka** — brauzerda [`EyeDropper` API](https://developer.mozilla.org/docs/Web/API/EyeDropper_API)
   bo'lsa (hozircha Chromium) ekrandan rang oladi; bo'lmasa tugma ko'rinmaydi.
5. **Hex input** — to'liq 6 (yoki 8) belgili hex darhol qo'llanadi; qisqa `#abc` — `Enter` yoki
   fokus chiqqanda. Noto'g'ri matn xato holatida ko'rinadi va fokus chiqqanda oldingi rangga qaytadi.
6. **Tayyor ranglar** (`swatches`).

Qiymat doim kichik harfli `#rrggbb` ko'rinishida qaytadi (`onValueChange('#0ea5e9')`).
Oq, qora yoki kulrang tanlanganda hue saqlanadi — slayder "sakramaydi".

## Field bilan

[`Field`](./field.mdx) ichida trigger nomi — label va joriy rang ("Brend rangi #0EA5E9"), izoh va
xato `aria-describedby` ga ulanadi. `name` — forma uchun yashirin `<input>`.

<ComponentPreview name="color-picker/with-field" align="start" />

## Shaffoflik

`alpha` — panelda shaffoflik slayderi chiqadi, qiymat `#rrggbbaa` bo'ladi (`#10b98180` — 50%).
Rang namunalari ostida shaxmat foni ko'rinadi.

<ComponentPreview name="color-picker/alpha" align="start" />

## Tayyor ranglar

Standart `swatches` — kutubxona palitrasidan 10 ta rang (`defaultColorSwatches` sifatida eksport
qilinadi). O'z palitrangizni bering yoki `[]` bilan yashiring.

<ComponentPreview name="color-picker/swatches" align="start" />

## O'lchamlar va holatlar

`size` — trigger balandligi Input bilan bir xil: `sm` 32px, `md` 40px (standart), `lg` 48px.
`disabled` — ochilmaydi; `invalid` (yoki `Field error`) — qizil chegara.

## Klaviatura

| Tugma                 | Qayerda     | Harakat                               |
| --------------------- | ----------- | ------------------------------------- |
| `Enter` / `Space`     | trigger     | Panelni ochish                        |
| `Esc`                 | panel       | Yopish, fokus trigger'ga qaytadi      |
| `←` / `→`             | 2D maydon   | To'yinganlik ±1% (`Shift` bilan ±10%) |
| `↑` / `↓`             | 2D maydon   | Yorqinlik ±1% (`Shift` bilan ±10%)    |
| `PageUp` / `PageDown` | 2D maydon   | Yorqinlik ±10%                        |
| `Home` / `End`        | 2D maydon   | To'yinganlik 0% / 100%                |
| strelkalar            | hue / alpha | Slider klaviaturasi                   |
| `Enter`               | hex input   | Kiritilgan rangni qo'llash            |

## Accessibility

- **Trigger** — oddiy `<button>`; `Field` ichida nomi label + joriy hex, aks holda
  `"Rang tanlash, #4F46E5"` (`aria-label` yoki `labels.trigger` bilan o'zgartiriladi).
- **2D maydon** — `role="slider"`, `aria-valuenow` (to'yinganlik) va ikkala o'qni aytadigan
  `aria-valuetext`: "to'yinganlik 80%, yorqinlik 60%".
- **Hue va shaffoflik** — `Slider` komponenti: `role="slider"`, `aria-valuetext` ("210°", "50%").
- **Tayyor ranglar** — `role="group"` ichida tugmalar, har biri hex nomli va `aria-pressed`.
- **Pipetka** — faqat API mavjud bo'lsa ko'rinadi (serverda va qo'llab-quvvatlamaydigan
  brauzerlarda yashirin), `aria-label="Ekrandan rang olish"`.
- **Rang yagona signal emas** — tanlangan swatch qo'shimcha halqa bilan ajratiladi, trigger hex
  matnni ham ko'rsatadi.
