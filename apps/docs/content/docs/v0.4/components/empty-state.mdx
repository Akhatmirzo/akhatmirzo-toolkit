
## Qachon ishlatish

- **Ro'yxat yoki jadval bo'sh bo'lganda** — "Buyurtmalar hali yo'q". Bo'sh oq joy o'rniga nima
  bo'lganini va keyingi qadamni ko'rsating.
- **Qidiruv yoki filtr natija bermaganda** — so'rovni o'zgartirish yoki filtrni tozalashni
  taklif qiling.
- **Birinchi kirishda** — foydalanuvchini birinchi harakatga yo'naltiring (`size="lg"`).
- **Bitta asosiy harakat** — `action` (`primary`), qo'shimchasi `secondaryAction` (`ghost`).
- **Sarlavha qisqa, izoh foydali bo'lsin** — "Hech narsa yo'q" emas, "Birinchi buyurtma kelganda
  shu yerda ko'rinadi".

## Qidiruvda natija yo'q

`bordered` — bo'lim ichida ishlatish uchun punktir chegara.

## O'lchamlar

`size`: `sm` — vertikal padding 24px, `md` (standart) — 40px, `lg` — 64px, ikonka doirasi 64px va
kattaroq sarlavha.

### Data atributlari

Ildiz elementda: `data-size`, `data-bordered` (punktir chegara bo'lsa). Stilni boshqa elementga
qo'llash uchun `emptyStateVariants` ham eksport qilinadi.

## Accessibility

- **Sarlavha haqiqiy `h*` tegi** — standart `h3`. Sahifa tuzilishiga moslab `headingLevel` bilan
  o'zgartiring, shunda sarlavhalar ketma-ketligi buzilmaydi.
- **Ikonka bezak** — doirasi bilan birga `aria-hidden`.
- **Harakatlar** — siz bergan tugmalar, klaviatura bilan odatdagidek ishlaydi. Tor ekranda
  (< 640px) ular ustma-ust va to'liq kenglikda turadi.
- **Natija dinamik o'zgarsa** (qidiruv), xabar e'lon qilinishini istasangiz, o'rab turgan
  konteynerga `role="status"` bering.
