## Import

```tsx
import { OtpInput, ResendTimer } from '@akhatmirzo/ui';
```

`ResendTimer` — `OtpInput.ResendTimer` sifatida ham mavjud, alohida import qilish shart emas.

## Qachon ishlatish

- **Telefon yoki email tasdiqlash, ikki bosqichli kirish** — SMS yoki ilovadan kelgan 4–8 xonali
  kod uchun.
- **Kod to'lishi bilan tekshiring:** `onComplete` oxirgi belgi kiritilganda chaqiriladi —
  "Tasdiqlash" tugmasi shart emas.
- **Xatoni matn bilan ayting:** `invalid` katakchalarni qizil qiladi va silkitadi, lekin sababini
  [Field](./field.mdx) ning `error` prop'ida yozing ("Kod noto'g'ri").
- **Qayta yuborishni taymer bilan bering** — `ResendTimer` foydalanuvchini SMS kelishini kutishga
  undaydi va serverni ortiqcha so'rovlardan saqlaydi.
- **Parol yoki PIN saqlash uchun emas** — belgilar ochiq ko'rinadi.

## Tasdiqlash oqimi

Yuqoridagi misolda to'g'ri kod — `123456`. Noto'g'ri kod kiritilsa, `invalid` yoqiladi:
katakchalar qizil bo'ladi va guruh yengil silkinadi. Foydalanuvchi qayta yoza boshlaganda xatoni
olib tashlang. Kod tasdiqlangach `disabled` qilib qo'yish mumkin.

```tsx title="VerifyForm.tsx"
import { Field, OtpInput } from '@akhatmirzo/ui';
import { useState } from 'react';

async function verifyCode(code: string) {
  const res = await fetch('/api/verify', { method: 'POST', body: JSON.stringify({ code }) });
  return res.ok;
}

export function VerifyForm() {
  const [code, setCode] = useState('');
  const [error, setError] = useState(false);

  return (
    <Field label="Tasdiqlash kodi" error={error ? "Kod noto'g'ri" : undefined}>
      <OtpInput
        value={code}
        onValueChange={(v) => {
          setCode(v);
          setError(false);
        }}
        onComplete={async (v) => setError(!(await verifyCode(v)))}
      />
    </Field>
  );
}
```

## Uzunlik, tur va guruhlash

`length` — katakchalar soni (standart `6`). `type="alphanumeric"` harflarni ham qabul qiladi
(standart — faqat raqam). `groupSize` katakchalarni guruhlarga ajratadi: `3` → `123 – 456`.

## ResendTimer

"Kodni qayta yuborish (0:59)" — taymer tugaguncha bosilmaydi. `onResend` Promise qaytarsa, u
tugaguncha ham bosib bo'lmaydi; keyin taymer qaytadan boshlanadi. Taymer komponent paydo bo'lishi
bilan boshlanadi — kod allaqachon yuborilgan deb hisoblanadi.

## Klaviatura

| Tugma          | Harakat                                                        |
| -------------- | -------------------------------------------------------------- |
| Belgi          | Katakchani to'ldiradi, fokus keyingisiga o'tadi                |
| `Backspace`    | Belgini o'chiradi; katakcha bo'sh bo'lsa — oldingisiga qaytadi |
| `Delete`       | Joriy katakchadagi belgini o'chiradi                           |
| `← →`          | Katakchalar bo'ylab yurish                                     |
| `Home` / `End` | Birinchi / birinchi bo'sh katakcha                             |

Bo'sh joydan keyingi katakchaga sakrab bo'lmaydi — fokus birinchi bo'sh katakchaga o'tadi.

## Accessibility

- **Guruh** — `role="group"`. `Field` ichida label orqali (`aria-labelledby`), tashqarisida
  "Tasdiqlash kodi" nomi bilan (`labels.group`) o'qiladi.
- **Har bir katakcha** — alohida `<input>` o'z nomi bilan: "1-raqam", "2-raqam" ... Boshqa tilda
  `labels.cell` bilan o'zgartiring: `cell: (i, n) => 'Digit ' + (i + 1) + ' of ' + n`.
- **`aria-invalid`, `aria-describedby`, `aria-required`** `Field` dan har bir katakchaga
  uzatiladi — xato matni qaysi katakchada bo'lmasin o'qiladi.
- **Mobil klaviatura:** `numeric` turida `inputMode="numeric"`.
- **Harakat sezgirligi:** silkinish `prefers-reduced-motion: reduce` da o'chadi.
- **ResendTimer** kutish paytida `aria-disabled` — fokusda qoladi, lekin bosilmaydi; taymer
  matni tugma nomining bir qismi.
