## Import

```tsx
import { HoverCard } from '@akhatmirzo/ui';
```

## Qachon ishlatish

- **Havola orqasidagi narsani oldindan ko'rsatish** — foydalanuvchi profili, mahsulot, hujjat.
  Foydalanuvchi sahifadan chiqmasdan "bu nima?" degan savolga javob oladi.
- **Faqat qo'shimcha ma'lumot.** Karta sensorli ekranda ochilmaydi va ekran o'quvchi uni
  o'qimasligi mumkin — trigger o'zi havola bo'lsin, ma'lumot esa havola ochadigan sahifada ham
  bo'lsin.
- **Qisqa matnli izoh** uchun — [`Tooltip`](./tooltip.mdx).
- **Ichida tugma, forma** kerak bo'lsa — bosish bilan ochiladigan [`Popover`](./popover.mdx).

## Tuzilishi

| Qism                | Vazifasi                                                          |
| ------------------- | ----------------------------------------------------------------- |
| `HoverCard`         | Holat va kechikishlar: `openDelay`, `closeDelay`, `open`          |
| `HoverCard.Trigger` | Havola (standart — `<a>`; o'z elementingiz uchun `asChild`)       |
| `HoverCard.Content` | Panel: Popover bilan bir xil ko'rinish, portal, joylashuv, `size` |

```tsx
<HoverCard openDelay={400}>
  <HoverCard.Trigger asChild>
    <a href="/u/akhatmirzo">@akhatmirzo</a>
  </HoverCard.Trigger>
  <HoverCard.Content side="bottom" align="start">
    …profil…
  </HoverCard.Content>
</HoverCard>
```

Karta kursor kelgandan **500ms** keyin ochiladi va kursor ketgandan **200ms** keyin yopiladi —
tasodifiy o'tib ketishda chiqmaydi, kartaga o'tish uchun esa vaqt qoladi. Klaviatura bilan
fokuslanganda ham ochiladi.

## O'lchamlar

`size` — `sm` (240px) yoki `md` (320px, standart). Boshqa kenglik uchun `className` bering.

<ComponentPreview name="hover-card/sizes" />

## Joylashuv

`side` — `top`, `right`, `bottom` (standart) yoki `left`; `align` — `start`, `center` (standart)
yoki `end`. Panel triggerdan 6px uzoqlikda turadi va ekran chetiga yetsa, teskari tomonga o'tadi.

## Accessibility

- **Faqat qo'shimcha.** Karta ekran o'quvchiga e'lon qilinmaydi va fokus unga o'tmaydi — undagi
  ma'lumot havola ochadigan sahifada ham bo'lishi kerak.
- **Klaviatura.** Trigger fokus olganda karta ochiladi, fokus ketganda yopiladi; `Esc` ham
  yopadi.
- **Sensorli ekran.** Touch bilan ochilmaydi — bosish havolaning o'zini ochadi.
- **Ichida interaktiv element** (tugma, forma) qo'ymang — ularga klaviatura bilan yetib bo'lmaydi.
  Bunday holatda [`Popover`](./popover.mdx) ishlating.
