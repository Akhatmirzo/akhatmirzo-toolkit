# Changesets

Har bir foydalanuvchiga ko'rinadigan o'zgarishdan keyin:

```bash
pnpm changeset
```

Qaysi paket o'zgargani va o'zgarish turi (patch / minor / major) so'raladi, natija shu papkaga yoziladi.
Nashr vaqtida `pnpm version-packages` versiyalarni oshiradi va CHANGELOG'larni yozadi.

`access` hozircha `restricted` — public/private qarori 8-bosqichda qabul qilinadi.
